评审说明 · 这是一个可交互原型

这是什么
本地资源库页面（Chrome 扩展内新开的一个页签）的高保真交互原型。用于评审交互与信息架构，不是最终产品。 所有数据是内置的 27 条演示数据，媒体样本来自公开网络；不会读取你电脑上的任何文件。
建议按这个顺序看（约 5 分钟）
1. 点左侧平台 → 看博主列表与封面随之变化；点某个博主 → 只看该博主
2. 点任意图片 → 灯箱：滚轮缩放、拖动、← → 切换、Esc 关闭
3. 点任意视频 → 弹层播发：↑ ↓ 切换视频、← → ±5 秒（Shift ±30 秒）、空格播放/暂停、Esc 关闭；勾选「自动连播」体验连续播放。
注意：播放条是自绘控件，不是浏览器原生 controls——因为原生控件会吞掉 ↑↓ 和空格（这正是审计发现的问题，已修）。
4. 工具栏切「按日期」→ 看时间线分组；切「列表」→ 看文件清单视图
5. 右键任意卡片 → 上下文菜单（播放/定位/复制路径/星标/重命名/移到回收站）
6. 勾选几项 → 批量条：复制路径、导出清单、删除
7. 左栏「回收站」→ 恢复 / 全部恢复 / 清空；「整理旧文件」→ 迁移预览（dry-run）
8. 星标与标签：卡片右上角 ★ 收藏；工具栏「星标」只看收藏；「全部标签」按标签筛选。键盘 J / K 移动高亮、Enter 打开、F 星标当前项
9. 图片灯箱底部有缩略图带，点击可直达；视频进度条上悬停显示该位置时间
10. 顶栏「命名规则」→ 目录结构与文件名模板说明

这个原型能验证什么
平台/博主/类型/标签/搜索/排序的过滤是否正确 · 星标与「只看星标」 · 图片灯箱（缩放 + 缩略图带）与视频键盘是否顺手 · 删除/回收站/重命名流程是否安全 · 迁移预览的文案与统计 · 时间线分组 · 右键菜单 · 视频悬停预览
交互设计参考了 Billfish / PhotoSwipe / Allusion / TagStudio / FileBrowser 等开源产品的用户习惯，代码全部为本项目自研，未引入或复制任何第三方源码。
不能验证（需要真实扩展环境）：真实文件读取与播放、下载落盘路径、写文件系统权限、迁移的复制/校验/回滚、万级大库性能。 原型里的视频样本只有 5 秒，因此「←→ 精确 ±5 秒」只能看到钳制到首尾的效果，长视频步进需在实现阶段复测。
完整方案（含 Chrome 限制、数据模型、风险审查、待质疑的 5 个点）见随附文档 LIBRARY-PLAN.md。
