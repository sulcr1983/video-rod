01

先说结论

三版都解决了"太满、太暗、太散"。差别只有一个：清单怎么排。

推荐

A · 收网

它最贴合你的真实动作：打开 → 看有几条 → 全选 → 下载。一屏能看 7 条，主按钮只有一个，改名在你点标题时才出现，不打扰。

后面要加"下载队列""历史记录"，往清单里加一行就行，不用重排布局。

什么情况下选 B / C

B 分堆——如果你更多是存图（小红书九宫格那种），喜欢一眼看到每条存到哪个文件夹。

C 一句话——如果你 90% 的时候都是"这个页面的我全要"，懒得勾。

03

你实际是怎么用它的

自用工具没有大数据，只能按真实场景推。三个场景覆盖了 95% 的使用。

场景 1 · 最常见

B 站下一整集 / 整个分P

目标：把这一集的视频拿到本地，名字别乱

1点工具栏图标，面板弹出
2看到"3 个视频"，默认已全选
3按「下载 3 个」
以前：3 次点击 + 先想"要不要改名字"；现在 2 次，名字不用管
场景 2 · 第二常见

小红书存九宫格

目标：9 张图，名字带作者，进作者文件夹

1切到「图片 9」
2扫一眼名字，个别改一下
3按「下载 9 个」
关键：名字默认就带作者 ID，9 张里改 1 张，不是改 9 张
场景 3 · 高频

看到就想存，不想开面板

目标：右键，直接下，不打断看视频

1在视频上右键
2「钓鱼竿：存这个」
3走智能命名 + 默认目录，完成
面板都不开，所以面板只为"批量"服务，不该塞日常设置
04

参考了谁

都是公开的产品和规范，学的是"为什么这样排"，不是抄皮。

Chrome popup 规范 规范

扩展弹窗硬上限 800×600，推荐宽 360–400；不能用 vh；头部固定、列表滚动、底部固定。

所以：380 宽、560 高，只让列表滚，头和脚永远在。
Nielsen 渐进披露 UX

主操作必须在第一层；次级内容一层就够；同一个功能别开两条路。

所以：设置只留一个齿轮入口，抽屉全部砍掉。
Linear 产品

用留白分组，不用边框；按钮形态全局统一；文字就是主角。

所以：清单靠 1px 分隔线和间距，不靠 7 个描边卡片。
Downie 4 竞品

有「简单模式」隐藏复杂项；下载按站点 / 播放列表自动分文件夹。

所以：默认值就是答案；分文件夹默认开，不用你设。
FluxDown 竞品

极简任务列表，只保留添加 / 批量管理 / 参数设置三件事，没有多余弹窗。

所以：面板只服务"批量下载"，工具类功能全部移出去。
Plucker 竞品

每条媒体可改名字、可指定文件夹，这是它比通用下载器好用的全部原因。

所以：改名不是隐藏功能，是核心动作——A 用悬停铅笔，B 用常驻输入框。

06

三版共用的底层规则

这些不管你选哪个都成立，也是"简单好用"的真正来源。

默认值即答案

  • 画质默认最高档，设置里可关
  • 文件名默认「作者_标题」，拿不到作者自动跳过该段
  • 目录默认按 站点/作者 分好
  • 面板打开时默认全选，不用先勾

信息只出现一次

  • 站点和数量合成一行，不单开信息条
  • 筛选收成一行文字，选中用下划线不用胶囊
  • 清晰度、大小、格式合成一行元信息
  • 一个主按钮，永远在右下，行内不再放下载图标

设置搬出面板

  • 面板里只留一个齿轮 → 独立设置页
  • 4 组、11 项，一屏看完：下载位置 / 命名 / 画质 / 面板
  • 删掉「更多工具」「更多功能」两个抽屉
  • 缓存捕捉、录制、深度搜索 → 收进设置页底部的「高级工具」

浅色不是"白底就行"

  • 正文 #0E1116 对白底 18.9:1；次要文字 #6B7480 5.1:1，都过 AA
  • 分隔线 #EFF1F4 只用来分组，不画满每一行
  • 勾选态用实心，不用彩色描边，避免"到处都是青色"
  • 所有点击区 ≥ 32px，键盘 Tab 能走完整个面板

07

落地：只改壳，不碰内核

另一条会话在写代码，所以这版特意按"CSS 优先"设计，尽量不打断它。

必须保留的 DOM 钩子（改名就崩）

#mediaList#allMediaList.container .TabButton.panel.DownCheck #DownFile#chkAll#vrBatchCnt #currentTab#allTab

#mediaList 和 #allMediaList 这四个容器的顺序不能动——标签切换是按索引映射的。

建议的动手顺序

1. 新增 css/popup-light.css，只做覆盖，不动 videorod.css 旧规则。

2. popup.html 删三层框架（页信息条 / 原生标签 / 筛选胶囊），换成两行。

3. 行卡片由 popup.js 生成：只改"标题 + 元信息"那一段拼接，其余结构别碰。

4. options.html 改成 4 组；面板里的两个抽屉直接删，不迁移逻辑。

三个坑，先说在前面

别用 vh 做高度。popup 的视口是由内容撑出来的，100vh 会算出怪值。固定 height:560px 或让内容撑。

别在面板里删"其他页"标签。猫抓的"其他页"是抓全站媒体的入口，删了会丢能力——它应该变成一行文字筛选，而不是消失。

改结构前先跑一遍批量下载。行内控件减少后，事件委托容易漏掉 .DownCheck 的 change，勾选数字就对不上了。

STEP 01

选一个方向

STEP 02

我出 v6 精细稿

STEP 03

交编程会话落地

按上面的 DOM 契约施工，只改壳；内核、嗅探、下载链路一律不动。
