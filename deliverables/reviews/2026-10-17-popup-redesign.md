# 钓鱼竿 popup 重设计 · 方案说明

> 日期：2026-10-17 ｜ 状态：评审中 ｜ 配套：`deliverables/prototypes/popup-redesign-options-v2.html`
> 一句话：**不是换皮，是把"每屏让你做决定"改成"默认就对了"。**

---

## 一、结论先行

| | 方案 | 一句话 | 建议 |
|---|---|---|---|
| **A** | 收网（清单式） | 打开就是一张干净清单，勾完按一个按钮 | ✅ **推荐** |
| B | 分堆（卡片分组） | 视频一堆、图片一堆，名字和目录一直摆明面 | 存图为主时选 |
| C | 一句话（默认识别） | 我替你选好、起好名、分好文件夹，只问下不下 | 懒得挑时选 |

推荐 A 的三个理由：

1. **一屏 5 条、行高 66px**（现在 3 条、行距挤）；一次抓十几种（一个 UP 主的视频+图片）时列表滚动、底栏合计和下载按钮固定不动，随时可点。
2. **主按钮只有一个**，行内不再有第二个下载图标，不用每次想按哪个。
3. **改名在需要时才出现**（点标题就地改），不打扰"默认名字已经很好"的 90% 情况。

B / C 不是陪跑：B 更适合小红书九宫格那种"一条条看完再存"，C 适合"这个页面我全要"的场景。三者可以后期融合（A 的清单 + C 的默认全选）。

## 二、调研依据（只列真影响决策的）

| 来源 | 关键结论 | 落到设计上 |
|---|---|---|
| Chrome 扩展 popup 规范（extension.js / mv3-extension.com） | 弹窗硬上限 800×600；推荐宽 360–400；**不能用 vh**；头固定、列表滚动、底固定 | 面板 380×560，只让列表滚 |
| Nielsen / IxDF「渐进披露」 | 主操作必须在第一层；次级内容一层就够；同一功能别开两条路径 | 设置只留一个齿轮入口，抽屉全砍 |
| Linear（浅色模式） | 用留白分组，不靠边框；按钮形态统一；文字是主角 | 清单用 1px 分隔线 + 间距，不用 7 个描边卡片 |
| Downie 4 | 有「简单模式」隐藏复杂项；按站点 / 播放列表自动分文件夹 | 默认值即答案；分文件夹默认开 |
| FluxDown | 只保留「添加 / 批量管理 / 设置」，没有多余弹窗 | 面板只服务批量下载，工具类功能移出 |
| Plucker | 每条可改名、可指定文件夹 —— 它比通用下载器好用的全部原因 | 改名是核心动作，不是隐藏功能 |

> 说明：也跑了本地 UI 知识库的配色/字体推荐，但它给的是"营销落地页"那一套（玫红 + 衬线），不适合工具面板，已弃用；配色按可读性自己定。

## 三、现在这版的 6 个问题（都能在面板里指出来）

1. **三层框架挡在内容前**：页信息条 + 4 个标签页 + 4 个筛选 = 110px，真正要下的东西排到第 4 层。
2. **两排"胶囊"干不同的事**：上面是"当前页/其他页"，下面是"视频/图片"，长得一样，分不清。
3. **每张卡片 4 个控件**：勾选、文件名输入框、文件夹按钮、单独下载图标 —— 7 条就是 28 个可点区。
4. **文件名输入框常驻**，等于每条都在问"要不要改个名"，而默认名字其实已经起好了。
5. **两个主按钮打架**：行内下载图标 vs 底部批量下载，视觉权重差不多。
6. **设置散在 4 个地方**：齿轮抽屉、更多工具抽屉、更多功能浮层、完整设置页。

| 指标 | 现在 | 改后 |
|---|---|---|
| 一屏可见 | 3 条 | **5 条**（66px/行，长列表滚动、底栏固定） |
| 每条控件 | 4 个 | **1 个**（勾选） |
| 进设置路径 | 4 条 | **1 条** |
| 面板底色 | 深色 + 青色高对比 | **浅色** |

## 四、三案共用的底层规则

**1）默认值即答案**

- 画质默认最高档（设置可关）
- 文件名默认「作者_标题」，拿不到作者自动跳过该段
- 目录默认按 `站点/作者` 分好
- 面板打开默认全选

**2）信息只出现一次**

- 站点和数量合成一行，不单开信息条
- 筛选收成一行文字，选中用下划线不用胶囊
- 清晰度 / 大小 / 格式合成一行元信息
- 一个主按钮，永远在右下

**3）设置搬出面板（4 组 9 项 + 1 个高级入口）**

| 组 | 项 |
|---|---|
| 下载位置 | 默认文件夹、按站点/作者分文件夹 |
| 命名 | 文件名规则、文件名自动整理（截断 60 字 · 重名 _01） |
| 画质 | 默认最高画质、m3u8 自动合并 MP4 |
| 面板 | 图片嗅探、数字角标、快捷键 |
| （入口） | 高级工具：缓存捕捉 / 录制 / 深度搜索 |

猫抓原生的那堆工具**不删能力，只换位置**：从"抽屉 + 浮层"收到设置页底部一个入口。

**4）10+ 也 hold 得住**（苏哥确认：一次抓一个 UP 主的全部视频+图片是常态）

- 列表允许滚动，但**底栏（合计 + 下载按钮）固定**，滚到底也能直接点
- A 行高 66px：比原先放松，长列表滚起来不累眼；筛选行带计数，十几条时先切「视频」再逐类下
- 原型内可切换「6 条 / 12 条」演示数据量，12 条为默认视图

**5）浅色 token**

| 角色 | 值 | 对比度 |
|---|---|---|
| 正文 | `#0E1116` | 18.9:1 |
| 次要 | `#6B7480` | 5.1:1 ✅ AA |
| 分隔线 | `#EFF1F4` | 仅分组用 |
| A 主色 | 墨黑 `#16181D`（按钮） | — |
| B 主色 | 深青 `#0F6E63` | 4.9:1 |
| C 主色 | 深墨蓝 `#0E2A47` | — |
| 勾选态 | 实心填充，不用彩色描边 | 避免"到处都是青色" |

点击区 ≥ 32px，键盘 Tab 可走完整个面板。

## 五、三案对比

| 维度 | A 收网 | B 分堆 | C 一句话 |
|---|---|---|---|
| 一屏可见 | 5 条（66px/行） | 2–3 条 | 首屏 1 个按钮 |
| 到下载 | 2 次点击 | 2 次点击 | **1 次点击** |
| 改名入口 | 点标题就地改 | 常驻输入框 | 展开后改 |
| 改目录 | 展开行详情 | 每条一个 chip | 默认分好，不显 |
| 图片批量 | 切「图片」筛选 | 天然分成一堆 | 折叠在"全部"里 |
| 学习成本 | 低 | 低 | 最低 |
| 以后加功能 | 好加（行可扩展） | 一般（分区会变多） | 难（藏得深） |
| 主要风险 | 改名不够显眼 | 条目少时显空 | 想挑时多一步 |

## 六、落地：只改壳，不碰内核

另一条会话在写代码，所以这版按"CSS 优先"设计。

**必须保留的 DOM 钩子（改名就崩）**

`#mediaList` `#allMediaList` `.container` `.TabButton` `.panel` `.DownCheck` `#DownFile` `#chkAll` `#vrBatchCnt` `#currentTab` `#allTab`

其中 `#mediaList` 与 `#allMediaList` 这四个容器的**顺序不能动**（标签切换按索引映射）。

**建议顺序**

1. 新增 `css/popup-light.css` 做覆盖，不动 `videorod.css` 旧规则。
2. `popup.html` 删三层框架，换成两行（站点+数量 / 类型筛选）。
3. 行卡片由 `popup.js` 生成：只改"标题 + 元信息"那一段拼接，其余结构别碰。
4. `options.html` 改 4 组；面板里的两个抽屉直接删，不迁移逻辑。

**三个坑**

- **别用 vh 做高度**：popup 视口由内容撑出，`100vh` 会算出怪值。
- **别删"其他页"标签**：它是抓全站媒体的入口，应变成一行文字筛选，而不是消失。
- **改结构前先跑一遍批量下载**：行内控件减少后，事件委托容易漏 `.DownCheck` 的 change，勾选数字就对不上。

## 七、验收标准（可量）

- [ ] 380×560 内可见 ≥ 5 条媒体；超过 5 条时列表滚动、底栏合计与下载按钮保持固定
- [ ] 打开面板到点下载 ≤ 2 次点击（默认全选时 1 次）
- [ ] 面板常驻控件 ≤ 8 个（不含每行勾选）
- [ ] 设置页 ≤ 10 项，最多翻半屏到底
- [ ] 每行只有一个可点区（勾选），改名/目录藏在"点标题 / 展开"里
- [ ] 正文对比度 ≥ 4.5:1，Tab 键能走完面板
