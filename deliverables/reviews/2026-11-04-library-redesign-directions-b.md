## 2. 方向六：天文台 Observatory

### 核心概念与风格定位
**库是天球，每条素材是一颗星。** 界面是一台观星仪器：深空蓝黑底、细线坐标、资源以"星点矩阵"排布。暗房是"暖的克制"（灯光、木桌、化学药水），天文台是"冷的诗意"（金属、玻璃、无垠深蓝）。深夜翻库不刺眼，是它的原生场景。

参照物：旧星图（蓝色印刷的 atlas coelestis）、天文台的目镜与刻度环、NASA 喷气推进实验室的数据界面（但去硬核化）。

**一句话原则：色彩与布局借星图，文案保持克制**——字段仍叫"大小/时间"，"星表"只是面板名，不滥用比喻。

### 视觉与交互要点

- **布局与栅格**：12 列。左 220px "星座栏"（平台=星座、收藏夹=命名星群、根目录=观测站状态），中部天幕画布为均匀的"星位矩阵"（等宽等高卡位，像星图点位），右侧"星表"面板按需滑出。顶部不是工具条，是一行**刻度读数**（条数/占用/索引态，右对齐，等宽，像赤经刻度）。
- **导航与层级**：两级封顶——星座（平台）→ 星点（素材）；博主降级为卡内元数据 + 搜索可命中，不做一层树。收藏夹以"星群"呈现，带自定名。
- **资源卡片**：1:1 方卡，深蓝面 #131826、1px 蓝线描边、2px 圆角。缩略图**默认压暗到 12% 亮度**（远观状态，整面墙像星图），悬停升到 100%（"望远镜聚亮"）。星标不是五角星，是卡右上角一个 4px 金色星点。平台色只以 4px 星点色出现。
- **筛选与搜索**：筛选=星座开关（点亮某星座，其余星点退到 30%）；搜索=**星座线——命中的条目之间连起 1px 金线，临时连成一个星座**，搜索框上方计数 `观测到 36 星`（标志性交互，全行业没人这么做过）。
- **信息与元数据**：点击卡片，右侧"星表"面板滑出——两列对齐、等宽 13px：编号（relPath 尾段）/ 星等（大小）/ 位置（路径）/ 发现日期（下载时间）/ 光谱型（格式）。分组微卡片：观测记录（文件）、来源（原帖/直链）、命名（标签）。
- **空状态与加载**：空=夜空参考环（两三圈细同心圆 + 中心十字 + 等宽 `NO OBJECTS`）；加载=**星星依次亮灯**——按伪随机"星等顺序"从亮到暗逐颗点亮（150ms 错峰），不是整齐扫描。
- **悬停与点击反馈**：悬停=亮度 12%→100%（200ms ease-out）+ 描边加亮至 1.5px + 右上浮出 1px 十字标线（观测校准）；点击=金描边 + 星表面板滑入 8px 位移。
- **字体排版**：栏目标题思源宋 20px + 字距 0.1em（星图注记的优雅）；正文思源黑 13px；**全部数值等宽**。字重 400/500 两档，轻而不虚。
- **间距节奏**：8/16/28/52。卡间 16px——"星距"要呼吸；区块间 52px；侧栏内 28px。整体比暗房更疏朗。
- **配色与材质**：底 #0B0E17（深空蓝黑，不是纯黑）、面 #131826、线 #2A3550、正文 #C7D2E8、次要 #67738C、**强调"星金" #D9B45F（只用于：选中、星座线、星标、危险操作以外的全部高光）**；危险红 #C4544A。材质记忆点：面板边缘 2% 白色内描线（目镜金属圈的冷反光）。
- **图标与图像风格**：1px 细线、纯几何（圆、弧线、十字——轨道与瞄准镜的语汇）；搜索图标=望远镜十字线；不用圆角方块底。缩略图不加滤镜，压暗靠 opacity。
- **响应式**：1440 全天空 + 常驻 240px 星表栏；1024 星表变覆盖式抽屉；860 星座栏收成顶部横向星座条（可滑动），卡距压到 8px。

### 适合谁 / 风险
- 适合：深夜翻库、想要"浪漫的克制"；冷暗对眼睛友好；万级素材时"星点矩阵 + 悬停才聚亮"天然抗视觉疲劳。
- 风险：默认压暗 12% 是双刃剑——第一次用可能觉得"看不清"，需要"常亮档"开关（默认悬停聚亮、可切全亮）；星座线要克制动画时长，否则变特效。

## 3. 方向七：宋册卷轴 Song Codex

### 核心概念与风格定位
**东方文人的留白与题跋。** 界面是一册摊开的卷轴：宣纸底、墨线框、靛青主色、一点朱砂（只在印/圈点/危险时用）。坚决不做"国风模板"——无云纹、无回纹、无金色描边、无水墨背景图，**只取版式的气韵**：竖排题签、卷轴段落、留白即设计。这是中文使用者审美的天花板路线：不炫技，处处收着。

参照物：宋刻本版式、日本「引敷物」挂轴装裱、内藤广的建筑制图（极简东方）。

### 视觉与交互要点

- **布局与栅格**：**卷轴制**——垂直滚动（桌面安全方案），内容按"段落"分卷（默认按月，可切按博主），每段右缘一条**竖排题签**（writing-mode: vertical-rl，思源宋 20px「贰零贰陆年 拾月」式或简洁「十月」）；段与段之间 80px 留白（"隔水"装裱术语，段间空白即呼吸）。侧栏=「卷袋签」：平台名竖排墨书感细体，选中=签纸微提+左侧 2px 靛青线。
- **导航与层级**：三级但弱化——卷袋（平台）→ 段（月/博主）→ 册（素材）。收藏与智能夹作为"另册"单列。
- **资源卡片**：**立轴卡（3:4）**——上部缩略图开"窗"（内嵌 1px 墨线框），下部大留白题跋区：竖排或横排标题（思源宋 20px）+ 一行小字元数据（等宽 11px：平台·日期·大小）。卡角无圆角或 2px，纯 1px 墨线，零阴影。视频卡在题跋区标一「影」字，图片标「绘」，收藏=盖一枚朱砂小印（方形 12px 白文印，替代五角星——辨识度爆点）。
- **筛选与搜索**：筛选=「分类线程」——顶部悬一排彩色线头（线色=平台色），垂下 16px 短线，选中=线头打结；搜索=**圈读——命中的标题字被朱砂细圈圈起**（传统"圈点句读"做高亮），整卡不消失只提亮，命中计数写在搜索线末端。
- **信息与元数据**：点击卡=右侧"题跋卡"展开（墨线两列表格）：部（平台）/ 来历（原帖链接）/ 年月（下载时间）/ 尺幅（分辨率）/ 体例（格式）；长值单行省略、悬停全显。
- **空状态与加载**：空=卷尾留白页（一行细墨线 + 右下角小字题「空卷 · 待入」）；加载=**墨晕**——卡片由淡到实浮现，墨线框从中心向四边洇开（150ms，ease-out，绝不回弹）。
- **悬停与点击反馈**：悬停=卡描边 1px→1.5px + 题跋区浮出一枚"批注"（等宽小字：时长/大小）；点击=靛青描边 + 题跋卡滑出。**全站动效只用"洇开"缓动，无缩放、无位移堆叠。**
- **字体排版**：思源宋是本方向的魂：标题/题签 20–24px（避开中文衬线小字发糊硬限制）、字距 0.25em（竖排必需）；正文思源黑 13px；数值等宽。全页仅三档字号——大、正文、注。
- **间距节奏**：64 页边距 / 80 段间 / 24 卡距 / 16 卡内。密度刻意低——**一屏 8–10 件，少即是贵**。
- **配色与材质**：底 #F6F3EC（陈纸）、卡面 #FDFBF5、墨 #26241F、次要 #7A756A、**靛青 #3E5C50（一切交互色）**、**朱砂 #B4432F（印/圈点/危险，仅此三用）**。材质记忆点：纸张 1.5% 暖噪 + 段落间一道极淡"界格线"（宋刻本版框）。
- **图标与图像风格**：细线 1.25px + 圆头收笔（笔锋感），零实心底；收藏不用星而用印；搜索用放大镜但去手柄装饰。
- **响应式**：1440 一页三列册；1024 两列 + 题签保留；860 竖排题签转横排、单列册、卷袋签收进顶部「目次」下拉（翻页式）。**水平滚动坚决不做**（桌面习惯红线），卷轴感靠段落与留白表达。

## 4. 方向八：唱片墙 Vinyl Vault

### 核心概念与风格定位
**博主=艺人，平台=厂牌，素材=唱片，库=唱片行。** 每条内容是一面方形封套，插在货架上；悬停抽套、点击落针即播。五个第一辑方向都在"博物馆/档案馆"的严肃区，唱片墙是唯一走进"收藏店"的方向——**玩心与珍存量并存**，最适合"我一件件钓回来的宝贝"这个产品故事。

参照物：黑胶唱片行的货架（Amo Music）、CMYK 唱片柜收纳系统、《High Fidelity》片头排版。

### 视觉与交互要点

- **布局与栅格**：**货架制**——主区按行排列（一行=一个货架格），每行左端一块"端签"（博主/平台名，竖排黄色标签纸，像唱片柜分区牌）；卡间 4px 紧贴（封套互相夹着的手感），行间 56px。侧栏=「厂牌目录」：平台=厂牌（粉色 Verve、蓝色 Blue Note 的标签纸质感列表），收藏夹=「精选合辑」。
- **导航与层级**：厂牌（平台）→ 艺人（博主=一行货架）→ 唱片（素材）。三级但在行内表达，不藏树。
- **资源卡片**：1:1 封套卡。封面满铺，左下角一枚小标签纸角（等宽：时长/张数，如 `3:42 · 单曲`）；封面下缘一条 6px 深色"封套脊"。**悬停=整面封套从"内袋"里抽出 8px；点击=封套完全左滑，露出右半张黑胶唱片（深色盘面 + 中心标签印平台色），唱针落下即播**（标志交互"抽套落针"）。
- **筛选与搜索**：筛选=「分区铁牌」——插在封套之间的金属色小牌（平台色顶边），点牌=只留该牌区；搜索=命中封套右上角贴一枚「再发现」贴纸（唱片行"新货"贴纸语汇），行尾计数 `36 张在售`。
- **信息与元数据**：点击落针同时右侧展开"歌词页"内页面板（像专辑内页/liner notes）：A 面=文件信息（大小/分辨率/格式/路径），B 面=来源（平台/原帖/直链/下载时间），底部「艺人其他唱片」=同博主关联素材横排小封套。标签纸质感、黑字印刷体。
- **空状态与加载**：空=空货架段（端签 + 一块空挡板的木纹阴影线）；加载=**进箱**——封套从右下方向左上"码"进货架（每张 100ms，错峰 30ms）。
- **悬停与点击反馈**：悬停=抽套 8px + 露出的唱片边缘高光线 1px；点击=封套左滑（200ms ease-out，无回弹）+ 唱针 SVG 落下 120ms。批量模式=封套整体下沉 4px 露勾选角标。
- **字体排版**：栏目标题思源黑 Heavy 收紧字距（唱片海报感）；正文思源黑 13px；**元数据全部等宽**（曲目表排版）。大中小三档，层级靠字重+底色块。
- **间距节奏**：4（卡距）/16（标签内）/56（行距）/40（页边）。**密而有序是货架的美德**——第一辑全在"疏"，本方向独占"密"。
- **配色与材质**：底 #211D18（胡桃木暗褐）、货架板 #2A2520、标签纸 #E8E1D2、正文 #E8E1D2、次要 #9A9184、**强调"橘纹" #D98E32（落针/贴纸/选中）**、危险 #B0413E。材质记忆点：褐调木纹底 + 泛黄标签纸，**与暗房（黑）、天文台（蓝）、舞台（黑金）全部错开**。
- **图标与图像风格**：1.5px 圆头细线，几何（播放=三角、回收=封套入箱）；图标色只两档：标签纸白 / 橘纹强调。

## 5. 方向九：标本柜 Specimen Cabinet

### 核心概念与风格定位
**自然史博物馆的标本学美学。** 素材=标本、博主=物种、收藏夹=模式标本；玻璃柜、黄铜角件、手写签卡，科学绘图式的精确与安静。第一辑的目录是"图书馆的纸"，本辑是"博物馆的玻璃与铜"——同走著录路线，但气质一冷一暖、一纸一玻。

参照物：自然史博物馆标本柜（灰绿帆布 + 黄铜角 + 签卡）、植物腊叶标本、Audubon 图版排版。

### 视觉与交互要点

- **布局与栅格**：**柜阵**——主区是「柜」的网格，每柜 1–6 件标本（默认单件大柜，筛选后多件小柜）；侧栏=分类学导航（界门纲目=平台→博主→作品，缩进 + 灰色阶小标签），层级即"分类等级"。顶部一条「馆藏读数」：件数/占用/入藏时间轴。
- **导航与层级**：柜门（平台）→ 抽屉（博主）→ 标本（素材）。面包屑用分类学措辞（淡灰小字，可点）。
- **资源卡片**：标本居中于柜面——缩略图**保留真实比例**，四周大留白（标本居中是仪式感），图四角叠 8px **黄铜 L 形角件**（标本固定夹），下方一条斜角白签卡：名称=文件名（衬线斜体——科学拉丁名的惯例把文件名当拉丁学名排版，全九向最大胆也最优雅的标识）+ 编号（等宽 `VR-00331`）+ 产地（平台·博主，11px）。
- **筛选与搜索**：筛选=分类等级开关（侧栏"目"级点亮）；搜索=**命中标本的签卡上出现一枚红色大头针**（针头压在标签上——标本采集语汇"已检视"），未命中的柜面整柜降透明度 40%，计数浮在搜索框右。
- **信息与元数据**：点击=右侧「登录卡」（accession card）滑出：入藏号 / 产地（来源链接）/ 采集人（抓取端）/ 采集日期（下载时间）/ 形态（格式分辨率）/ 质量（大小时长），科学式两列表，签卡纸底。
- **空状态与加载**：空=空柜（一根细框线 + 一张空白签卡斜置「待登录」）；加载=**上台**——卡从 97% 放大回 100% 落位 + 四角铜件依次出现（各 60ms）。
- **悬停与点击反馈**：悬停=玻璃面一条对角掠光扫过（250ms，只一次，不循环）+ 签卡上浮 2px；点击=铜件描边加亮 1px + 登录卡滑出。
- **字体排版**：名称栏衬线斜体（思源宋不可斜体——中文文件名用常规宋体、英文文件名才斜体，两轨制，这是要实测的坑）；分类标签全大写拉丁小字距；正文思源黑 12px；编号等宽。三档字号 + 两档字色就够——标本学的安静来自"字少"。
- **间距节奏**：柜面 padding 20（居中留白）、柜间 32、栏间 48、页边 56。低密度——**一柜一物，物以稀为贵**。
- **配色与材质**：底 #EDEFEA（灰绿博物馆白）、柜面 #FFFFFF、框线 #C9CFC3、正文 #2E332B、次要 #77806F、**强调"黄铜" #A08543（角件/选中/链接）**、**"针红" #B0413E（大头针/危险，仅此两用）**。材质记忆点：黄铜角件 + 签卡纸的"一点点折角阴影"（唯一允许的非零阴影，≤2px 柔和）。
- **图标与图像风格**：1px 解剖图式几何细线；放大镜图标=标本检视镜；星标统一换成"大头针"。
- **响应式**：1440 三柜一排；1024 两柜 + 登录卡抽屉化；860 单柜一排、分类学侧栏收进顶部「检索等级」下拉、掠光动效自动关闭（prefers-reduced-motion 同样关闭）。

### 第二辑内推荐（以及跨辑总排序）

1. **天文台 Observatory —— 第二辑首选。** 与暗房同为"可天天用"的深色，但冷蓝把"质感"从工艺感转向精密仪器+星图的诗意；星座线搜索是九向中唯一"截图会被传播"的交互；压暗悬停聚亮对万级素材库是真实的功能解法（抗疲劳），不只是好看。
2. **宋册卷轴 —— 若苏哥要"最不像工具、最像自己书房"。** 文化辨识度全场第一，最贴"克制、有辨识度、避免 AI 感"；代价是密度，需简册模式兜底。
3. **唱片墙 —— 若要"话题性与收藏玩心"。** 辨识度最高但最贵最冒险，适合当"彩蛋模式"而非主界面。
4. **标本柜 —— 精致小品。** 图片多的库（小红书重度用户）最诚实的展示法，海量库效率是短板。
