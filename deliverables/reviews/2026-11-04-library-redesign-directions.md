# 资源库页面重设计 · 五方向评审稿

> 版本：v1.0 ｜ 2026-11-04 ｜ 状态：**评审中（待苏哥拍板）**
> 配套上下文：`.impeccable.md`（设计上下文）、`docs/DESIGN-SYSTEM-BD.md`（现行 B+D token）、`docs/STYLE-OPTIONS.md`（上轮四方向，已选 B+D 落地）
> 本轮定位：**换一套新的视觉语言 + 标志性交互**，不是在 B+D 上微调。五个方向是**五种风格立场**（色温、材质、交互哲学全不同），不是五种配色。

---

## 0. 为什么重做

一句话：B+D 皮肤用了一个月，**好用但看腻了**；资源库页至今还带着"后台表格感"，离"高端大气、有质感"还差一层材质与主次。

本轮要解决的三个真问题：
1. **图像没有当上主角**——现在缩略图挤在真表格、KPI 卡、筛选器之间，打开页面先看到的是界面，不是照片；
2. **深色下没有主次**——D 影院深色背景里，界面元素和图像混在一起，谁也不提气；
3. **没有标志性交互**——看过就忘。本轮每个方向必须自带一个"一看就记得住"的动作。

交付物：5 个方向，每个完整覆盖 12 个细节维度 + 响应式策略。苏哥选定后，下一阶段产出高保真 HTML 可交互原型。

## 2. 方向一：暗房 Darkroom

### 核心概念与风格定位
**图像先于一切。** 整个界面是一间暗房：近黑暖底，图像是唯一被照亮的物体，界面退到"暗房工具"的位置——像摄影师在暗房里挑底片：照片是主角，工具是陪衬。

参照物：银盐暗房、国家档案馆数字馆藏、Eagle 的深色浏览感（但比 Eagle 更克制、更"展览"）。

### 视觉与交互要点

- **布局与栅格**：12 列栅格。图像占 10 列（4:3 或 16:9 自适应），左右留 1 列"暗房导轨"做缩略图轨。所有页面元素不与图像抢列宽。
- **导航与层级**：侧栏只放三样——平台（编号 01–09）、收藏夹（星标/智能夹）、根目录状态。**不展开资源树**，博主信息降级为卡片下方一行等宽字。层级：平台 → 内容，两级封顶。
- **资源卡片**：**恒定外框（画框垫边）**——每张缩略图四周留 16px 暗色留白，像装裱好的画。缩略图永不占满单元。
- **筛选与搜索**：筛选 = **"开灯/关灯"拨杆**——选中=灯亮，未选中=灯灭但保留轮廓（压 40% 亮度，不隐藏）；搜索 = **聚光灯**——只有命中区域被照亮，其余全压到 12%。
- **信息与元数据**：缩略图下方一行**等宽打字机式标签条**（编号 `BTV-2024-00331`、平台、博主、时间、尺寸）。悬停时标签条展开为"放大镜读数"（分辨率、时长、格式、路径）。
- **空状态与加载**：空 = 暗房空轨道（一条暗淡导轨线 + 等宽字 `NO FRAMES`）；**加载 = 显影**——新条目从无到有淡入，像照片在显影液里浮现。
- **悬停与点击反馈**：悬停 = 2px 暖光晕边缘 + 四角 8 个定位框角标（暗房放大定位框）；点击 = 进入全屏"放大灯箱"：舞台全黑、图像居中放大、两侧是暗房夹具式快门控制条。
- **字体排版**：标题用思源宋（≥24px，中文衬线硬限制内最大值）；正文思源黑 13px；**元数据一律等宽**（Noto Sans Mono 子集）。字重对比拉到 200 vs 700。
- **间距节奏**：8/16/24/40/64，永远 1:2 递进。图像之间的间距大于图像与工具之间的距离——"展品与展墙"。
- **配色与材质**：主底 #0D0C0A（暖近黑，不是冷 #0A0A0A）、卡面 #17150F、文字 #E8E3DA、次要 #8A8478、**强调 #E8A24A 暖金（暗房安全灯）**；平台色只出现在等宽编号与 1px 色条上。
- **图标与图像风格**：Lucide 细线 1.5px；点状/打孔标记代替圆角方块；图标在暗底上用 60% 亮度（不刺眼）。
- **响应式**：1440 = 全尺寸工作台（大画框）；1024 画框缩小、标签条收成一行；860 侧栏收成横条、只留平台编号条。

## 3. 方向二：档案室 Archive

### 核心概念与风格定位
**国家档案馆式的精密与诚实。** 页面是摊开的档案柜：抽屉标签列 + 档案卡片区 + 查阅登记簿。信息密度高，但每一行都"有来历"——像翻看旧档案，每一页都值得停留。

与现有 B 纸感的区别：B 是"线上文档的纸感"（干净、轻），Archive 是"物理档案柜"——更厚、更重、有手泽。**B 是"看文件"，Archive 是"翻档案"。**

### 视觉与交互要点

- **布局与栅格**：12 列。左 2 列"抽屉标签列"（竖排平台名，像档案抽屉标签）；中 8 列档案卡片区；右 2 列"查阅登记簿"（当前筛选、计数、最近操作流水）。
- **导航与层级**：侧栏 = 档案柜抽屉。点击平台 = **拉开抽屉**（标签位移 + 抽屉拉出的阴影感动画）；收藏夹 = "夹在抽屉里的分隔签"。层级：抽屉（平台）→ 卡片，两级。
- **资源卡片**：标准档案卡（A6 比例 1:1.414）。顶部印刷标题（思源宋 18px）、中部缩略图（1px 描边 + 极轻内阴影模拟纸面起伏）、底部著录行（日期/来源/格式）、**左下角手写感索书号**（`2024-BILI-00331`）。
- **筛选与搜索**：筛选 = **打孔卡式过滤签**——每个条件是一张带小圆孔的卡片签，勾选 = 插入分类签，排成一行；搜索 = "检索目录卡"，支持交集/排除语法，实时展示检索式（等宽）。
- **信息与元数据**：右侧登记簿实时流水（最近操作、索引状态）；卡片 hover 底部展开"著录详情"（著录项 dt/dd 两列对齐，等宽编号）。
- **空状态与加载**：空 = 空档案柜（一排空抽屉标签 + 柔和阴影）；**加载 = "归档"动效**——卡片从顶部滑入落定，落位时 120ms 纸面压痕（阴影收拢一下再稳）。
- **悬停与点击反馈**：悬停 = 纸面轻抬（-2px + 阴影加重）；角部出现**归档戳**印章图标（点击进入批量/操作菜单）。
- **字体排版**：标题思源宋 24px（放宽字距 0.08em）；正文思源黑 13px；索书号/编号等宽。字重对比中等（400 vs 700）。
- **间距节奏**：12/24/36/60，以 12 为基。卡片间距 24px，抽屉列与卡片区之间 48px（"柜体深度"）。
- **配色与材质**：主底 #FAF7F0（象牙）、卡面 #FFFFFF、次级 #E8E0D0、文字 #2B2620、**强调 #A8502E（档案印泥赭石）**、深档 #1E1A14；纸面微噪纹理（极轻，不抢戏）。
- **图标与图像风格**：Lucide 细线 1.25px；关键图标（搜索/筛选）用"印章式"变体（外方内圆）；缩略图保留真实材质，不套滤镜。
- **响应式**：1440 三栏；1024 登记簿收成卡片 hover 展开；860 抽屉变横条、卡片单列。

## 4. 方向三：仪表盘 Precision

### 核心概念与风格定位
**一台资源库监测仪。** 一切以 1px 青色描线切割，信息像仪表读数一样精准排布。整个界面是一台"会说话"的机器——不讨好你，只给你准确读数。

参照物：老式广播电视设备面板、瑞士设计（Swiss style）、示波器界面。**这是最"冷"的一个方向。**

### 视觉与交互要点

- **布局与栅格**：严格 24px 栅格，**网格线可见**（极淡 1px 青线）；顶部"读数条"（`lib=1,234  du=12.3GB  idx=SYNCED  space=3.2TB` 硬核读数，等宽）；左侧竖排"量程选择器"。
- **导航与层级**：侧栏 = 刻度档位。平台是"量程档位"（01 CH–09 CH），收藏夹是"预设档"。点击档位 = 档位指示点亮。
- **资源卡片**：**小方卡（1:1）拼合**，卡间 1px 描线，2px 小圆角；每卡顶部一条 3px 平台色"指示灯条"。信息极简：文件名（不换行省略）+ 时长/尺寸等宽读数。
- **筛选与搜索**：平台筛选 = **一排拨动开关**（选中=拨上，带"咔哒"微震动反馈）；搜索 = "频段扫描"——输入词后界面显示 `LOCKED 36 项` 并高亮命中。
- **信息与元数据**：点击卡片打开"仪表读数面板"——固定右侧面板，等宽 13px 行，字段名小写无衬线、值等宽右对齐，像仪器校准数据表。
- **空状态与加载**：空 = 示波器空屏（网格 + 中心十字 + 等宽 `NO SIGNAL`）；**加载 = 仪表扫描**——读数条跳变，卡片从左到右逐个点亮（扫描式）。
- **悬停与点击反馈**：描线加粗到 2px + 右上角"测量光标"十字线；点击 = 光标锁定卡片 + 弹出读数条。
- **字体排版**：标题用无衬线（思源黑粗 + 收紧字距，避开 Inter）；正文思源黑；**一切读数用等宽**（数字是灵魂）。
- **间距节奏**：8 基（8/16/24/40），永远对齐 24 栅格。视觉上"零浪费"。
- **配色与材质**：底 #F4F6F4（微绿冷白）、线 #C8CED0、文字 #1A2024、**强调 #E8A200 琥珀警示灯**、深档 #101518；平台色只做 3px 指示灯条，不大面积。
- **图标与图像风格**：1px 描线、几何规整（圆/方/线，无曲线装饰）；搜索图标做成"示波器探针"；缩略图加 1px 冷线描边（像仪表照片）。
- **响应式**：1440 全功能；1024 侧栏收成横排档位条；860 读数条两行、卡片两列。

## 5. 方向四：舞台 Stage

### 核心概念与风格定位
**整个资源库是一个剧场。** 默认环境是"空场"（舞台灯未亮），资源是舞台上的演员。筛选 = 剧场调光，搜索 = 追光灯，预览 = 大幕拉开。**戏剧性是主角。**

参照物：剧场、电影院、MoMA 白盒子展厅。这是**辨识度最强**的方向。

### 视觉与交互要点

- **布局与栅格**：不是常规栅格，是"舞台平面图"——顶部"场灯控制条"（环境光、亮度、筛选）；中部舞台平面（正交视角，无透视变形）；资源卡是舞台上的"灯位/演员位"；左侧"剧目单"。
- **导航与层级**：侧栏 = 剧目单（剧院节目单排版：编号、剧名、数量、日期）。平台 = 剧目，收藏夹 = 幕次。
- **资源卡片**：卡片是舞台灯位图上的方块，带"灯位编号"（`L-01`）；进入页面时环境光 30% 亮起，卡片呈暗场轮廓。
- **筛选与搜索**：平台 = 色灯分组（每平台一个色温）；"只看星标" = 聚光灯只留主角；**搜索 = 追光灯——只有命中的区域被照亮，其余压到 12% 亮度**（标志性交互）。
- **信息与元数据**：悬停 = 该灯位点亮 + "演员卡"（标题/时长/尺寸/来源）；点击 = 大幕拉开，全屏预览（深色舞台 + 图像居中 + 顶光渐变）。
- **空状态与加载**：空 = 空场（舞台平面 + 一束顶光 + 等宽 `CURTAIN`）；**加载 = 演员登场**——卡片从舞台两侧滑入。
- **悬停与点击反馈**：悬停 = 该卡区域环境光瞬间提升（light pool 聚光）+ 1.02 缩放 + 2px 光晕；四角有"灯位四角架"标记。
- **字体排版**：标题大字号思源宋（28–40px，剧场海报感）；正文思源黑；编号用等宽 + 剧场编号格式（`ACT 1 / SCENE 3 / cue-012`）。
- **间距节奏**：宽松（32/48/64），留出舞台感——**信息之间故意留白，让灯光说话**。
- **配色与材质**：底 #100F0E（剧场黑）→ 舞台区 #191715；文字 #E8E3DA；**强调 #E8B04B 舞台金**；聚光用暖光径向渐变；平台色做灯位色带。
- **图标与图像风格**：Lucide 细线，但关键图标改成"灯具"形态（聚光灯、追光、脚灯）；缩略图在暗场里微微提亮（图像仍是焦点）。
- **响应式**：1440 舞台平面全览；1024 舞台变两列"侧台"布局；860 剧目单收成横条、灯位卡单列。

## 6. 方向五：目录 Catalog

### 核心概念与风格定位
**1900 年代图书馆卡片目录的现代转译。** 每一条目都是一张标准档案卡（3.5×5 英寸），卡片柜排列；平台 = 分类字母，收藏夹 = 特别收藏部。

参照物：巴黎国家图书馆、牛津 Bodleian 馆藏目录、旧卡片目录柜。**最"印刷感"、最"精致小品"的方向。**

### 视觉与交互要点

- **布局与栅格**：12 列，卡片按 3 列一柜排列；卡片柜之间有"抽屉导轨"细线；顶部"目录大厅"（深色金属灰 + 印刷感）。
- **导航与层级**：侧栏 = 目录抽屉索引（A–Z 分类 + 数字 + 特藏"收藏夹"）；点击分类 = 抽屉滑出该类卡片。
- **资源卡片**：标准 3.5×5 比例卡。顶部印刷标题（思源宋 18px）、中部缩略图（1px 印刷描边 + 纸面阴影）、底部著录行（作者/来源/日期）、**左上索书号**（等宽 `B-2024-00331`）、**右上角装饰条码**。
- **筛选与搜索**：筛选 = 目录柜顶部"引导条"——筛选条件一个个"夹"在引导条上（像图书馆目录柜的金属引导条）；搜索 = 目录卡检索，实时显示命中。
- **信息与元数据**：点击卡片进入"借阅卡"详情——右侧面板像借阅记录卡（书名/作者/索书号/条码/日期/备注），字段以印刷表格呈现。
- **空状态与加载**：空 = 空目录柜（空导轨 + 空抽屉标签 + 等宽 `NO MATCH`）；**加载 = 插卡动效**——卡片从顶部滑入落位（像插入卡片），落位带 100ms 纸面压痕。
- **悬停与点击反馈**：卡片上浮 3px + 描边加深 2px + **右上角条码变红**（图书检索感）；点击 = 卡片被"翻开"，正面是详情。
- **字体排版**：标题思源宋 18–24px（印刷感）；正文思源黑 12px；索书号/条码等宽；字距标题 0.04em。
- **间距节奏**：16/24/32/48；卡片间留"柜内间隔"（24px），比档案室更"收藏感"。
- **配色与材质**：底 #F2EEE4（旧纸色，比档案室更黄更旧）、卡面 #FBF8F0、文字 #2A2620、次要 #8A8070、**强调 #1E4D6B（图书馆深蓝）**、深档 #1B1814。
- **图标与图像风格**：Lucide 细线 1.25px；"搜索"用放大镜+书；"收藏"用星形书签；缩略图保留原色，仅 1px 描边。
- **响应式**：1440 三柜；1024 两柜 + 抽屉索引横条；860 一柜单列。

## 7. 对比与建议

### 五方向差异矩阵

| 维度 | 暗房 | 档案室 | 仪表盘 | 舞台 | 目录 |
|------|------|--------|--------|------|------|
| 色温 | 暖黑 | 暖白象牙 | 冷白描线 | 剧场黑 | 旧纸黄 |
| 材质隐喻 | 暗房/画框 | 档案柜/卡纸 | 仪器/金属线 | 舞台/灯光 | 卡片柜/印刷 |
| 交互哲学 | 采光开关 | 拉抽屉 | 拨杆读数 | 聚光/追光 | 翻卡/插卡 |
| 标志性动作 | 显影加载+放大灯箱 | 抽屉拉出 | 仪表扫描点亮 | 追光灯搜索 | 条码索书号 |
| 图像地位 | **最高** | 中 | 低（读数优先） | 高（追光） | 中 |
| 整理能力(标签/收藏) | 中 | **高** | 中 | 中 | 高 |
| 日常耐看度 | 高 | 高 | 低（冷） | 中（需低调档） | 中高 |
| 迁移成本 | **最低** | 低 | 高（全新冷系） | 低（接D影院） | 中（全新色系） |

### 我的推荐（按优先级）

1. **暗房 Darkroom —— 首选推荐。** 理由：图像优先符合"钓鱼竿=存素材"的第一场景；显影加载与放大灯箱是唯一的"一看就记得住"的动作；直接接 D 影院深色，迁移成本最低；克制成色最符合"高端大气不模板化"的要求。
2. **舞台 Stage —— 若苏哥想要"惊艳感与辨识度"**。追光灯搜索是五个方向里最有戏剧性、最不容易被模仿的交互，但需要配套"低调模式"压住日常使用的戏剧感。
3. **档案室 Archive —— 若苏哥更重视"整理与归类的仪式感"**。抽屉拉出 + 著录卡是整理党的快乐，但材质要做重，否则退回 B 纸感。
4. **目录 Catalog —— 备选。** 精致但复古，适合小体量库（几百条），海量数据下不如暗房扛得住。
5. **仪表盘 Precision —— 不建议主选。** 冷峻专业，但日常使用情感温度最低，且改动量最大。
