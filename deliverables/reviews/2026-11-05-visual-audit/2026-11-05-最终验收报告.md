### 3.3 播放器选型说明（联网调研结论）

| 候选 | 结论 |
|---|---|
| Video.js 8 | 最成熟（Apache-2.0，2010 至今），但体积大、默认皮肤厚重、需额外字体资源 |
| Vidstack | 活跃、MIT，但 Web Components API 集成成本高 |
| Shaka | DASH/HLS/DRM 专用，本地 MP4 场景用不上 |
| Media Chrome | ADR-046 已否决 |
| **Plyr 3.8.3** | **选用**：单 JS + 单 CSS + 内嵌 SVG sprite，完全离线、CSS 变量直接对齐舞台金，集成最省 |

如实说明：Plyr 官网已标记 deprecated（仅安全更新）。本扩展只用它播放本地 MP4，功能稳定；
接口已收敛在 `lightbox.js` 的 `new Plyr(...)` 一处，将来换 Video.js 成本低。
此决策写入 `docs/DECISIONS.md` **ADR-055**，覆盖 ADR-046 中关于播放器的部分（依据苏哥当晚明确指令）。
