# 平台货架改版 · 变更规格（PRD / Spec）

> 2026-11-09 ｜ 状态：**待苏哥拍板** ｜ 依据原型：`media-library-shelf-compact-v1.html`（已验收 5 张实机截图）
> 本文是**施工唯一依据**。编码会话只按 §2 清单改，§3 红线一律不碰，任何超出范围的改动必须先回到本文件加条目。

---

## 0. 一句话

媒体库首页从「**平铺卡片墙**」改为「**平台货架**」：每个平台固定一行横向货架，超出部分右缘渐隐、点「查看全部 N 项」进平台内页。**详情页、下载链路、数据结构一律不动。**

为什么改：素材量上千后，平铺墙里不同来源混在一起，找不到"我从某站抓的那一批"。平台数量有限（≤10）而批次无限，所以用平台做行，行数天然封顶。

---

## 1. 改版前 → 改版后（一图看懂）

| | 改版前（现状） | 改版后 |
|---|---|---|
| 首页结构 | 单一 `.grid` 平铺，`minmax(185px,1fr)` | 每平台一个 `.shelf`，行内 128px 卡 + 右缘 64px 渐隐 |
| 分组 | 无（按保存时间倒序平铺） | 按 platform 分组，行内按保存时间倒序 |
| 卡片 | 185px+，双行标题，平台角标 + 平台列 + 时间列 + 标签行 | 128px，单行标题，无平台角标，大小/时间 hover 浮层 |
| 筛选 | 只有类型 seg | 一条筛选条（类型 + 时间 + 已星标 + 更多筛选）+ 已选条件栏 + 抽屉 |
| 平台筛选 | 靠左树点击 | 行头「查看全部 N 项 →」进平台内页（面包屑 媒体库 / 平台） |
| 搜索 | 标题行一个 + 左树一个（重复） | **只保留标题行一个** |
| 排序 | 原生 `<select>`（深色下白底弹层） | 自绘深色下拉 |

## 2. 变更清单（只改这些）

> 「落点」列到文件 + 函数/class 级。验收口径见 §7。

### R1 · 首页改为平台货架渲染　【B-61 · P0】

- **改什么**：列表渲染从「平铺 grid」改为「按 platform 分组 → 每组一个货架行」
- **落点**：`js/library/app.js`
  - `render()` 的列表部分（现输出 `.grid` 卡片）
  - 新增 `renderShelves(list)`：按 `platform` 分组 → 每组输出 `.shelf` 结构
  - **每行最多渲染 12 张**（超出不渲染，避免 1000 条铺 DOM）
- **不动**：`toCardModel()` / 排序 / 搜索 / 批量选择逻辑
- **验收**：行数 = 有素材的平台数；每行 ≤12 张；行头计数 = 该平台实际条数；5 万条首屏不卡

### R2 · 货架行视觉（紧凑卡）　【B-61 · P0】

- **改什么**：新增货架专用样式，**卡片基础规则不动**
- **落点**：`css/library.css` 追加 `.shelf / .shelf-head / .shelf-line` 段
  - 卡片：`flex:0 0 128px`；标题单行（`display:block;height:auto;white-space:nowrap`）
  - 隐藏平台角标/平台列/时间列：**只在 `.shelf-line` 作用域内隐藏**（`.shelf-line .card .badge{display:none}` 等）
  - 右缘渐隐：`.shelf-line::after{...width:64px;background:linear-gradient(90deg,transparent,var(--bg) 78%)}`
  - 行头：3px 平台色条 + 平台名（13.5px/650）+ 金色等宽计数 + 「N 项 · 最近 时间」+ 右侧「查看全部 N 项 →」
- **硬约束**：**禁止修改 `.card` 全局规则**（`library.css:369` 起）与 `.grid`（353 行）——列表视图、批量选择全依赖它们
- **验收**：网格视图与列表视图切换后视觉无回归；1440 / 1000 两种宽度均无断档

### R3 · 平台内页　【B-61 · P0，依赖 §5 batchId 决策】

- **改什么**：点行头/「查看全部」→ 面包屑变「媒体库 / 平台」，列表只显示该平台
- **落点**：`js/library/app.js`
  - 复用现有 `S.plat` 筛选状态（不新增路由、不新增页面）
  - `renderTree()` 的 active 态同步
  - 面包屑文案切换
- **降级**：若 §5 batchId 不落地，平台内页就是该平台的时间线网格（无批次组头），功能仍完整
- **验收**：进入后计数正确、左树对应节点高亮、面包屑可点返回；返回后首页状态不丢

### R4 · 筛选条（新增时间/星标维度）　【B-62 · P0】

- **改什么**：现有 toolbar 只有类型 seg；扩为一条完整筛选条
- **落点**：`library.html` toolbar 区 + `js/library/app.js` 筛选状态 `S`
  - 新增：时间（全部/今天/本周/本月）、已星标、更多筛选按钮、右侧「共 N 项」
  - 保留：类型 seg、选择、排序、视图切换（位置不变）
- **数据**：`savedAt`（已有）、`starred`（已有）——**零新增字段**
- **验收**：任一筛选生效后「共 N 项」= 实际可见卡片数

### R5 · 已选条件栏（新增）　【B-62 · P0】

- **改什么**：有筛选时，筛选条下方出现一行「已筛选：[条件 chip ×] … 清除全部」
- **落点**：`library.html` 新增 `.activebar`；`app.js` 渲染 + 单个删除
- **验收**：每个条件可单独 ×、全清可恢复默认；无筛选时该行不占位

### R6 · 更多筛选抽屉（新增）　【B-62 · P1】

- **改什么**：右侧 380px 抽屉，四组条件 + 实时命中 + 清除/完成
- **落点**：`library.html` 复用现有 `.setdrawer / .sd-*` 骨架（**不要新建抽屉组件**）；`app.js` 渲染
- **条件组**：大小（<1MB/1–10MB/10–100MB/>100MB，单选）、分辨率（4K/1080p/竖构图，单选）、标签（多选交集）、作者（多选）
- **数据**：`size` / `width,height`（F1 已回写）/ `tags` / `creatorFull` —— **零新增字段**
- **验收**：底部命中数与主界面「共 N 项」一致；「更多筛选」按钮带数字徽标；Esc/遮罩关闭

### R7 · 排序改自绘下拉　【B-63 · P1】

- **改什么**：`<select id="sort">` → 自绘深色下拉
- **落点**：`library.html:206-214` 替换；`css/library.css` 新增 `.dd/.ddmenu`；`app.js` 交互
- **同类问题**：`#batchByType`（批量"按类型"）也是原生 select，同一套改法，可一并处理
- **原因**：原生 select 弹层由系统渲染（白底/蓝高亮），深色皮肤下必然冲突，CSS 无法覆盖
- **验收**：下拉为深色、选中项金色对勾、点空白收起；键盘可选

### R8 · 空态补筛选语境　【B-62 · P1】

- **改什么**：`#empty` 存在且有「清除筛选」，只补文案与按钮口径
- **落点**：`app.js` `renderEmpty()`
- **验收**：无结果时提示「没有匹配的素材」+「试试放宽条件」+「清除全部筛选」，一键可恢复

### R9 · 删除左树搜索框　【B-64 · P2】

- **改什么**：删 `library.html:113-116` 的 `.tree-search` 与 `#treeSearch`；删 `app.js` 对应事件绑定
- **不改**：左树结构、编号体系、收藏/标签区
- **验收**：左树正常渲染与点击；页面只剩一个搜索框（标题行）

## 8. 验收口径（可测，不接受"看起来差不多"）

1. 首页行数 = 去重后的 platform 数
2. 每行卡片数 ≤ 12，且行头计数 = 该平台实际条数
3. 1440 与 1000 两种宽度：行内卡片连续、右缘有渐隐、**无断档空白**
4. 任意筛选组合后「共 N 项」= 实际卡片数；空结果必出「清除全部筛选」
5. 卡片高度一致（无空带）；标题单行截断
6. 详情页字段与改版前**逐项一致**（截图对比，任何新增/缺失即判定失败）
7. 列表视图/网格视图切换、批量选择、回收站、设置抽屉：**无回归**
