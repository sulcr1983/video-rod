# B 站「又下载不了」+ 媒体库左上角点了不是换文件夹（B-72）

苏哥 2026-11-12 两条报障，都不是「下载/选目录」本身坏了，而是**判断逻辑把正常操作当成了重复**和**入口被删后指错了地方**。

---

## 一、B 站下载不了：真因是去重按「整条页面」记账

### 1.1 现象

点下载按钮，浮标闪一下绿勾就恢复原样，没有文件、没有提示。再点也一样。
用户的理解必然是「下载不了」，实际返回的是 `{ ok: true, skipped: true, reason: 'duplicate' }`。

### 1.2 根因链

| # | 问题 | 后果 |
|---|---|---|
| 1 | 去重键 `vrMediaIdentity` 对 B 站只能拿到 `pick.url`，而 B 站的选项是 `durl`/`dash`（**没有直链 URL**） | 键退化成「整条页面 URL」 |
| 2 | 一条 B 站页面可能有几十集（分P/合集），页面 URL 相同 | 下过一集之后，**再点任何一集都被判重复** |
| 3 | `vrFindExistingMedia` 的兜底同样是 `pageUrl + type=video` | 库里已有该页视频 → 直接 `duplicate-source` 跳过 |
| 4 | 跳过时浮标只 `flash('done')`（一个绿勾），与「下载成功」无法区分 | 用户无法判断「已下过」还是「坏了」 |
| 5 | （顺带发现）`probeFunc` 用 `__INITIAL_STATE__.videoData.cid`，SPA 切 P 不刷新 SSR 数据 | 切到第 3P 点下载，下的是第 1P |
| 6 | （顺带发现）B 站命名在 probe 之前就算好，拿不到 UP 主信息 | 所有 B 站文件名都挂着同一个 `(@360421127)`（串了别人的 mid）；多P 全同名 |

### 1.3 修法

- **作品键**：`bvid_cid`（每集一个），去重时再拼档位 `_durl` / `_dash`
  - 同一集同一档：第二次跳过（正确去重）
  - 同一集换档：放行（先下 720P 后悔了还能下 1080P）
  - 不同集：互不影响
- `vrFindExistingMedia` 新增 `workId` 比对：有作品键时**不再**用 pageUrl 兜底判断
- 浮标新增页内提示条（`.vr-votoast`）：
  - 跳过 → 「这一集（同清晰度）刚下过，没有重复下载」/「这个视频已经在库里了」
  - `no-option` → 「没问到可下载的视频：先让它播几秒再点…」
  - `download-failed` → 「下载失败：换个清晰度再试，或刷新页面」
- `probeFunc`：URL 带 `?p=N` 时取 `pages[N-1].cid`，并带回 `partTitle` / `ownerMid`
- 命名改为 probe 之后计算，用探针给的作者名 + mid（只传名字，`buildAuthorFull` 自己拼 `(@ID)`，避免重复）

### 1.4 验证（`tools/test-bili-source.py` 12/12）

| 断言 | 结果 |
|---|---|
| T1 options.meta.workId = `BV1GJ411x7h7_137649199` | PASS |
| T2 首次 durl 真起下载（52MB，complete） | PASS |
| T2 文件名带作者 ID 且不重复 | PASS |
| T2 同集同档二次 `skipped` | PASS |
| T3 换档位（durl→dash）仍 `started` | PASS |
| T4 `?p=2` → cid=222 / `?p=3` → 333 / 越界退回主 cid | PASS |

真机另测：durl 720P 51.9MB、dash 1080P 76.7MB 都完整落盘到 `B站/<作者>/`。

## 二、媒体库左上角：点了跳到设置页，不是换文件夹

### 2.1 为什么是这样

2026-11-10 设计评审认为「路径卡点开设置页」与「设置里的保存位置」重复，于是：

- 设置弹窗里的「保存位置」整组**删除**（注释写「换目录走左栏路径卡」）
- 左栏路径卡的点击**改成 `openOptions()`**（跳到完整扩展设置页）

结果两边都没有换目录入口 —— 点路径卡只会跳到一个满是开关的设置页，体感就是「换了个地方」，而不是换文件夹。

### 2.2 改成什么

| 点击位置 | 行为 |
|---|---|
| 路径卡主体 | **直接弹系统文件夹选择器**，选完切换库根并重新扫描 |
| 右侧小箭头 | 仍去完整扩展设置（次级入口保留） |

安全护栏（避免误点把库「弄空」）：

1. 若选中的是「下载」这类上级目录，且里面有 `video-rod`，自动下钻进去
2. 先数一眼新目录里有多少媒体文件（限量 200，深度 3）；**一个都没有**时二次确认：
   「换过去后现在库里的 N 条会显示不出来（文件还在原文件夹，没被删）」
3. 取消选择（AbortError）静默，不弹错误
4. 切换后写 `vrLibSettings.mode='custom'` + `customName`，路径卡显示**文件夹名**（浏览器只给句柄不给绝对路径，什么都不显示会让人以为没生效）

### 2.3 验证

CDP 拦截 `showDirectoryPicker` / `openOptionsPage`：

| 操作 | 期望 | 实测 |
|---|---|---|
| 点路径卡主体 | 选目录 1 次、不跳设置 | pick=1, opt=0 |
| 点右侧小箭头 | 跳设置 1 次、不弹选目录 | pick=1, opt=1 |
