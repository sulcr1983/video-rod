# 钓鱼竿 video-rod 施工计划 v1

> 配套：PLAN.md（方案书 v1.3）+ popup-prototype-v5.html（交互原型，deliverables/prototypes/，浏览器直接打开）
> 策略：**外壳大改、内核不动**——猫抓的嗅探内核/下载器/FFmpeg 合并一律不碰，保证随时能 cherry-pick 上游更新；所有新功能以独立模块挂在壳上，一个模块坏不影响其他。
> 节奏：按里程碑推进，**每个里程碑结束都有可验收的实物**，不满意就地整改再往下走。全程 git 托管，每阶段一个回滚点。

## 一、里程碑总览

| 阶段 | 目标 | 预估 | 验收实物 |
|---|---|---|---|
| M0 地基 | 智能起名引擎 + 页面识别模块 | 1-2 天 | 输入任意网址，输出干净的文件名（控制台可验） |
| M1 面板 | popup 列表外科手术（改名/目录/清晰度/分P/筛选） | 2-3 天 | 加载扩展，面板和原型长得一样 |
| M2 下载 | 带目录下载 + 批量队列 + 去重 | 2 天 | 测试站视频真实落进 Downloads/video-rod/xxx/ |
| M3 B站 | 分P/合集嗅探增强 + DASH 合并（零签名对抗） | 1-2 天 | 多P纪录片全下 + 大会员验证 |
| M4 YouTube | 嗅探验证 + 页面列表展开（降级，不开发签名） | 0.5-1 天 | 公开视频能下；明确限制边界 |
| M5 周边 | 图片批量 + 右键秒存 + 快捷键 + 完成提示 | 2-3 天 | 小红书图片批量存、右键直接下 |
| M6 打磨 | 细节打磨 + 全功能回归 + 使用说明 | 1-2 天 | 交给苏哥日常用的成品 |

合计约 **1.5-2 周**（2026-10 审计改版后：M3/M4 从签名对抗改为搭便车嗅探，省下约 5 天；每天投入几小时的节奏，集中赶工可压缩到一周内）。

## 二、为什么这个顺序

```
M0 命名引擎 ──► M1 面板 ──► M2 下载管线 ──► M3 B站嗅探增强 ──► M4 YouTube 验证 ──► M5 周边 ──► M6 打磨

   （地基）      （外壳）      （管道）        （搭便车，零签名对抗）  （降级验证）
```

- **M0 最先**：起名是全局依赖——每个下载动作都要用它，先造好，后面所有模块直接调用
- **M1-M2 是主干**：面板+下载管着日常体验，做完就已经是个能用的工具了（视频嗅探+改名+分目录+批量）
- **M3/M4 放后面**：两家是独立模块，谁先做谁后做互不影响；搭便车路线下踩坑风险已大降，一家不顺先上另一家，不阻塞
- **M5 最后**：图片/右键/快捷键都是锦上添花，挂在成熟的主干上最省事

## 三、每个阶段干什么（大白话版）

### M0 地基：起名引擎 + 认页面（1-2 天）
- 给模板引擎加新变量：作者（昵称@ID）、正文、序号——B站签名的 JS 实现直接抄开源库
- “认页面”模块：文章页取标题剥网站名、推特页取正文和作者、认不出就退回网页标题
- 清洗三件套：非法字符换下划线、超长截 60 字、重名自动加序号；拿不到的信息自动跳过不留空
- **验收**：拿 10 个真实网址（新闻/推特/B站/普通页）跑一遍，输出文件名个个干净

### M1 面板：列表大改（2-3 天）
- 照原型 v5 重做列表卡片：文件名随手改、目录 chip（默认目录/最近/新建）、清晰度下拉（默认自动最高）、B站卡带「分P ×N」
- 底部操作栏：全选/批量命名/批量下载 + 顶部类型筛选（全部/视频/图片/流媒体）
- 设置抽屉：默认目录、命名模板、图片嗅探、主动抓取等开关
- **验收**：扩展装上，面板和原型一模一样；所有按钮可点有反馈

### M2 下载：真落盘（2 天）
- 下载带目录：`Downloads/video-rod/平台/作者/名字.mp4`
- 批量队列：勾选几条就排队下几条，错峰不卡浏览器，完成面板内汇报
- 去重：同一个地址下过就记住，防手残重复下
- **验收**：测试站勾 5 个视频批量下，文件夹里整整齐齐

### M3 B站模块（1-2 天，2026-10 审计改版：零签名对抗）

> 原计划「抄 bilibili-API-collect 的 WBI 签名」已作废——该仓库 2026-01-28 律师函关停，
> B站下载开源生态集体团灭（ADR-019/020）。新路线不做任何签名对抗：

- 分P列表从页面 DOM/状态读取（不调 API、不碰 WBI 签名）
- 面板展示分P卡，用户勾选 → 扩展驱动页面切换分P（浏览器自己去请求）
- 猫抓嗅探浏览器实际发出的 DASH 流（m4s 直链）→ 下载 + 合并（合并路线按 DESIGN §8）
- 大会员内容天然支持（浏览器能播放=请求已带 cookie=嗅探即得）
- 失效自动退回纯嗅探模式
- **验收**：随便找个多P纪录片/番剧，面板列出全部分P，勾选全下；再找个大会员视频验证登录态

### M4 YouTube 模块（0.5-1 天，2026-10 审计改版：降级验证，不开发）

> 原计划「抄 avi12 的签名 decipher」已作废——2026-01 起 YouTube 强制 SABR+poToken，
> 「没有 Chrome 扩展能可靠下载 YouTube 视频」（ADR-019）。纯扩展对抗无性价比：

- 只做验证：普通视频/播放列表页，猫抓嗅探能抓到什么就抓什么
- 页面数据展开播放列表条目（只取已加载项，不滚动）——能做多少做多少
- 抓不到的部分明确标记「当前 YouTube 限制」，不死磕
- 苏哥若刚需 YouTube：启动备选路决策（m3u8dl 外挂 N_m3u8DL-RE，PLAN 决策点 #8）
- **验收**：公开视频能下则下；明确知道什么场景下会抓不到，不死等

### M5 周边补齐（2-3 天）
- 图片批量：扫页面（img/背景图/懒加载）+ 滤小图 + 和视频同款卡片管理
- 右键秒存：网页视频/图片右键直接下（抄 VDH）
- 快捷键 Alt+Shift+V 唤起面板
- **验收**：小红书/微博图片批量存；右键视频直接落盘

### M6 打磨交付（1-2 天）
- 空状态、错误提示、深色细节；全功能回归一轮
- 写一份大白话使用说明
- **验收**：苏哥日常随便用，找不到茬

## 四、丑话说前面（风险与对策）

| 风险 | 影响 | 对策 |
|---|---|---|
| B站/YouTube 生态继续恶化 | M3/M4 抓取能力打折 | 零签名对抗路线天然免疫大半；失效退回嗅探；2026-10 快照见 ADR-020，生态回暖可重估 |
| 在线FFmpeg 隐私（合并走远程服务） | 视频分片上传第三方 | DESIGN §8 三路线；设置留开关（⏳ 待苏哥拍板） |
| 站点 DOM 改版 | 分P列表/页面识别失效 | 退回网页标题/纯嗅探兜底 |
| Chrome 大版本禁 unpacked | 扩展掉线 | 重装一次即可，配置在 profile 里不丢 |
| 改造改坏猫抓内核 | 全盘崩 | 内核不动；每阶段 git 回滚点，坏就退 |
