## 1. 一句话

**界面浅色（暖白纸感），画面深色（影院沉浸）。**

不是"浅色主题 + 深色主题"，是两套人设各管一段：
- 你在**管理**素材时，看的是列表和信息 → 暖白不累眼、不偏色
- 你在**看**素材时，看的是画面 → 近黑让画面跳出来

Eagle、Lightroom、Photoshop 全是这个组合。

### 预览层（不管当前主题，永远是 D）

在 `.preview` 上**局部覆盖同一批变量**，里面的组件自动变深色，不需要给任何组件写第二套样式：

```css
.preview{
  --surface:#12141A; --ink:#F4F6F9; --accent:#FF7A45;
  /* …完整一套 D 的 token… */
  background:#0A0B0E;
}
```

**这是本轮最重要的工程决定**：一套 CSS 两套皮肤，改一个组件两边同时生效。

## 3. 形状与尺度

| 元素 | 圆角 | 说明 |
|---|---|---|
| 卡片 | **12px** | 比按钮小，因为卡片是"容器" |
| 按钮 | **999px（胶囊）** | 主/次/危险全部胶囊 |
| 输入框 | 999px（搜索）/ 9px（表单） | 搜索是胶囊，表单不用 |
| 统计卡 | 12px | |
| 弹窗 | 15px | |
| 右键菜单 | 13px | |
| 抽屉 | 0（贴边） | 只有左侧圆角 |

> **一条铁律**：同屏圆角不超过 3 种。原来的界面同时出现 7px / 9px / 10px / 14px / 18px / 999px，这是"看着廉价"的根因。

### 字号

| 层级 | 字号 | 字体 |
|---|---|---|
| 页面大标题 | 32px | **衬线** |
| 预览标题 | 22px | **衬线** |
| 区块标题 | 13px | 无衬线 600 |
| 正文 | 12.5px | 无衬线 |
| 辅助 | 11px | 无衬线 |
| 微字 | 9.5–10px | 无衬线 |

### 界面字体（2026-11-04 晚 苏哥拍板换字体）

| 用途 | 字体 | 许可 |
|---|---|---|
| 正文/UI 全部 | **思源黑体 Noto Sans SC**（400/500/700） | OFL 免费商用 |
| 大标题/预览标题（衬线） | **思源宋体 Noto Serif SC**（700） | OFL 免费商用 |
| 回退栈 | -apple-system → Segoe UI → PingFang SC → 微软雅黑 | 系统 |

**为什么换**：原 Georgia+宋体在 Windows 深色底渲染又糊又土（苏哥：「字体非常奇怪，不协调」）。思源黑体是中文界面事实标准，字重全、深色清晰。
**落地方式**：原型经 jsdelivr 演示；**正式实现=子集化 woff2 自托管进扩展**（打包本地、离线可用、不依赖 CDN——旧「不引 webfont」结论修订为「不引 CDN webfont，自托管子集字体」）。子集化工具 cn-font-split，正文包预计 2~4MB（unlimitedStorage 无压力）。

### 衬线的硬限制（仍然有效）

**衬线只能用在 ≥20px 的地方。** 中文衬线小字号会糊；正文、按钮、标签全部无衬线黑体。

## 4. 组件规范（关键几条）

### 卡片
- 比例 **16:10**（不是 4:3），一屏能多看一行
- 边框 1px `--line`，阴影极轻；hover 上浮 2px + 阴影加深
- **不做**顶部色条、渐变标题、装饰下划线这类花活
- 平台徽标：浅色下白底深字，深色下深底亮字（同一位置，两套对比）

### 按钮
- 全部胶囊
- 主按钮：浅色 = 近黑实心；深色 = 橙渐变 + 光晕
- 次按钮：1px 边框 + 面板色
- 危险按钮：只在 hover 时出现红底，常态只有红字

### 侧栏
- 底色比主区**深半档**（`--surface-2`），靠色差分层次，不用粗边框
- 收藏夹与资源树之间一条极淡分隔线
- 选中项：面板色底 + 左侧 2.5px 强调色竖条
- 计数不加胶囊底（原来那圈灰底让侧栏显脏），直接灰色数字

### 右键菜单
- 最小宽 **212px**（原来的 186px 会让 `Del` 贴到边框上）
- 行高 8px padding，图标 14px，快捷键右对齐且左边留 18px

### 预览层
- 舞台：#07080A 径向渐变，圆角 14px，四周留 14px
- 控件条：半透明深色 + 毛玻璃，圆角 14px
- 信息栏：#12141A（比舞台亮一档，形成面板感）
- 强调色暖橙：进度条、连播开关、倍速选中档
- 全屏时**隐藏**右下角的主题切换按钮（用 `:has()` 实现，不改 JS）

**交互回归**：收藏夹 15 项、主界面 9 项、倍速 11 项断言全 PASS，0 JS 错误。
换肤只改 CSS 与 token，**没有动一行 JS**，所以原有交互零回归。
