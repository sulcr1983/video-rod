# 入口层功能与按钮审视（不只是配色）

> 版本：v1.0 ｜ 日期：2026-11-04 ｜ 状态：**待苏哥审批**
> 起因：苏哥要求「不仅页面颜色，功能、按钮都要想，展示什么更方便用户用」。
> 方法：从**用户真实动作**倒推每个界面该展示什么、放什么按钮，而不是把功能堆上去。
> 铁律约束：**N-05 下载按钮恒取最高画质**（苏哥已定）→ 主流程不逼用户选清晰度；**默认就对了，高级选项不占主界面**。

---

## 一、先想清楚：用户打开这些界面，到底在干什么

| 场景 | 用户脑子里的一句话 | 界面必须秒答 | 不该出现 |
|---|---|---|---|
| 点图标弹 popup | 「这页有啥能下的？我要下哪几个？」 | 类型 + 数量 + 每条是什么 | 清晰度下拉、切源、媒体控制 |
| 视频页浮层 | 「把这个视频下了」 | 一个下载键 + 大小 | 画质菜单（默认最高，要改再点箭头） |
| 图片悬停 | 「存这张 / 存这页全部」 | 单张 + 全部两个键 | 尺寸档位（那是清单面板的事） |
| 批量抽屉 | 「挑几条一起下」 | 可勾选列表 + 已下过的置灰 | 重复下已存的 |

**核心原则**：主路径三步——**看清有什么 → 勾要下的 → 一键下**。其余全收进二级。

---

## 二、popup：功能与按钮的具体取舍

### 2.1 砍掉 / 降级（现在占了主界面但用户几乎不用）

| 现状 | 问题 | 处理 |
|---|---|---|
| 「媒体控制」页签（切源 / 合并） | 猫抓底座遗留，普通用户看不懂、用不上 | **从主界面移除**，收进齿轮→高级 |
| 逐条清晰度下拉 | 违背 N-05「恒取最高」，且逼用户做技术选择 | 主界面不显示画质；展开详情里给「改画质」入口 |
| 筛选 chips + 勾选 两套重复 | 既筛又勾，语义打架 | chips 只负责「筛选显示」；新增「按类型一键全选」 |

### 2.2 新增（用户真需要，现在没有）

| 新增 | 为什么方便 | 位置 |
|---|---|---|
| **本页概览条**：`视频 4 · 图片 1 · 流 1`，点某类=只勾选该类 | 纪录片分P「全下视频」一次点完，不用逐条勾 | 站点条下方 |
| **「存到」一行**：显示目标文件夹，点可换 | 用户最关心「下完去哪」，现在完全看不到 | 概览条右侧 |
| **「已下载」标记**：下过的行灰显 + 角标 + 「忽略已下载」开关 | 对应 F-12，避免重复下浪费时间 | 每行 |
| **底部下载键带体积**：`下载 4 · 约 340 MB` | 下之前知道量，硬盘心里有数（对应 F-5） | 底部 |
| **默认最高画质徽标**：`画质 最高 ▾` 小字，点开才改 | 尊重 N-05 默认最高，但给高级用户一个总开关 | 概览条 |

### 2.3 保留（已经好用）
- 顶栏三图标（设置 / 媒体库 / 侧边栏）
- 收网清单：勾选 + 缩略图 + 标题（点改名）+ 展开看路径
- 快捷设置抽屉 + 「完整设置页」大按钮

## 三、设置页：两层要不要合并（待拍板）

**现状问题**：齿轮 → 面板内「快捷设置抽屉」→ 还要再点「完整设置页」才开新标签 options。普通用户以为齿轮就是全部设置，找不到第二跳。

**三个方案**：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A 维持两层 | 快捷抽屉放高频开关 + 底部「完整设置页」按钮 | 常用项不用开新标签 | 第二跳仍可能找不到 |
| **B 齿轮一步直达（推荐）** | 齿轮直接开 options 新标签，popup 里不放快捷抽屉 | 心智简单：齿轮=设置，只有一处 | 改个「默认最高画质」要开新标签 |
| C popup 内做全量设置 | 把 options 全部搬进 popup 抽屉 | 不出面板 | popup 380 宽塞不下，等于重做 |

**我的建议**：**B**。设置只有一处（完整设置页），齿轮一步到位；popup 底部保留一个「常用：默认最高画质 / 忽略已下载」两个开关即可，不叫「设置」。

## 四、页面侧注入 UI：展示什么更顺手

| 元素 | 现在 | 建议 | 理由 |
|---|---|---|---|
| 图片悬停按钮 | 「下载原图 / 全部 N」 | 单张按钮加**尺寸或体积**（如「下载原图 2400×1600」） | 用户想知道存的是不是大图 |
| 视频浮层主钮 | 「下载」 | 已下过显示「已存 ✓」再点才重下 | 对应 F-12，防重复 |
| 批量抽屉列表 | 全部可勾 | **已下载的置灰**（配合「忽略已下载」） | 一眼看出还剩几条没下 |
| 清单面板 | 已有档位/过滤/勾选 | 保持，档位已是「展示什么」的正解 | — |

## 五、竞品印证（2026-11-04 调研，苏哥要求参考成功产品）

> 调研对象：Video DownloadHelper(800万) / Fatkun(400万) / Image Downloader / Chrono / Download All Images / B站助手类 / Powerful Pixiv Downloader / 上游猫抓。

| # | 共性做法 | 谁在做 | 我们的状态 |
|---|---|---|---|
| 1 | 「有货即亮灯」：角标数字提示有可下内容 | VDH/猫抓/Chrono | ✅ 已有（数字角标） |
| 2 | **每行独立下载按钮**（不强制先勾选） | VDH Quick Download/B站助手/Fatkun | ❌ **缺 → 本轮补** |
| 3 | 入口分层：popup+悬浮+右键+快捷键 | 几乎全部 | ✅ 已有 |
| 4 | 点缩略图即选中 + Shift 范围选 | Pact/Fatkun/猫抓 | ✅ 已有 |
| 5 | 筛选代替逐个挑：类型/尺寸/URL | 全部 | ✅ 已有（chips+档位） |
| 6 | 画质在条目内展开，不单独弹窗 | VDH/B站助手 | ✅ 默认最高（N-05）+ 展开里改 |
| 7 | **路径零打扰**：下载前不让选路径，自动分流 | 除 Chrono 外全部 | ✅「存到哪」只展示+点击才改 |
| 8 | **去重防重复** | **仅 Pixiv Downloader** | ❌ 全行业缺口 → **我们做成差异化**（有 IndexedDB） |

**最大启示**：去重是行业没人做好的事，而钓鱼竿有本地资源库（IndexedDB 全量比对能力），「已下载标记」不只是防重复，应是产品级差异化卖点。

## 六、拍板结论（2026-11-04，苏哥授权按第一性原理定）

| # | 待定项 | 拍板 | 依据 |
|---|---|---|---|
| 1 | 「媒体控制」页签 | **砍**，收进完整设置页 | 竞品共性 9：popup 只放操作与列表 |
| 2 | 设置两层 | **齿轮一步直达完整设置页**，popup 内不再有快捷抽屉层 | 共性 9 + 高频开关已上概览条，抽屉冗余 |
| 3 | 页面侧白底抽屉 | **统一深色玻璃**（微博/小红书/X 同一套） | 浮在任意网页上高对比优先；组件统一消灭"这个一样那个一样" |
| 4 | 页面侧已下载提示 | **做**，且升级为差异化卖点 | 共性 8：行业没人做好，我们有库 |
| 5 | popup 每行独立下载按钮 | **加**（hover 行内出现单条下载键） | 共性 2：一键即下，不强制勾选 |
| 6 | 主按钮画质策略 | **恒最高**（守 N-05），画质在展开详情内改 | 共性 6：条目内展开，不单独弹窗 |

> 下一步：popup v3.2（每行下载键 + 齿轮直达）、页面侧 v2（统一深色玻璃胶囊 + 已存标记）落地后一并提审。
