## 7. 铁律/坑（别再踩）

1. **目录选择不做内容白名单**。空目录合法；用户选什么就接受什么，最多提示 0 文件。
2. **苏哥要 F，不要 E**。别再按“E 有文件”反推目标；E 现在只是 junction。
3. **`showDirectoryPicker` 不要固定 `id`**；固定 id 会记忆目录。选择器窗口可能被主窗口盖住，媒体库已改独立 popup。
4. **重命名必须 `move(parentDir, newName)`**；`move(newName)` 在星愿抛 `NotAllowedError`，且 `move()` 返回 `undefined`。
5. **外部目录隔离**：`xbd-downloader`/`老黄的分享` 保留但不扫描；不要把 704 个外部文件重新扫进媒体库。
6. **`_index`/`_trash`/`_thumbs`/隐藏目录** 不扫描。
7. **X/Twitter、微博、小红书** 都有风控：只读不等于零风险；批量 3–5 秒/条、失败即停；小红书自动补全默认关闭。
8. **抖音/微博的 CDN Referer**：直链下载优先页面内 fetch/blob；失败回退 DNR，不是所有站都能用 downloads 裸下。
9. **XHS 详情** 只读 `__INITIAL_STATE__.note.noteDetailMap`；主页/收藏/点赞只做半手动收集，不自动翻页。
10. **YouTube 不做**（SABR + PO Token）：页面悬浮按钮与 popup 横幅都已移除，别再给它加回入口；Instagram P1 代码已做（真实登录态验证挂起）。
11. **媒体库缩略图自动补缺**：`scan()` 后自动生成缺失缩略图（视频串行、图片并发）；要加新的缩略图来源，走 `generateThumb`/`fillMissingThumbs`，别在渲染里另起一套。
12. **全屏验证要先把标签页聚焦**（`Page.bringToFront`）；后台标签全屏必失败，别误判成按钮坏了。
