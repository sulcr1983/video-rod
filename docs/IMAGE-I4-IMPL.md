## 2. 浮标

### 2.1 外观

```
右下角，距边 16px，直径 40px 圆形
┌────────┐
│  🖼 23 │   ← 图标 + 角标（可下张数）
└────────┘
```

| 规则 | 值 |
|---|---|
| 位置 | `right: 16px; bottom: 16px`（可拖动后记住偏移，存 `localStorage['vrImgFloatPos']`） |
| 尺寸 | 40×40，圆角 50% |
| 角标 | 张数，>99 显示 `99+`；为 0 时**不渲染浮标** |
| 层级 | `z-index: 2147483000`（低于悬停条 2147483001，避免挡住下载按钮） |
| 拖动 | `pointerdown` + `pointermove` 拖动；拖动距离 <4px 视为点击 |
| 关闭 | 右键或面板内 × 关闭本页浮标（`sessionStorage['vrImgFloatOff']=1`，刷新恢复） |
| 遮挡 | 靠近站点自己的悬浮组件时半透明（`opacity:.45`，悬停恢复） |

### 2.2 数量更新

- 页面加载后算一次；
- `MutationObserver` 监听 `document.body` 子树新增 `<img>`，**1s 节流**重算；
- 滚动不重算（懒加载由 observer 覆盖）。

## 3. 清单面板

### 3.1 结构

```
┌──────────────────────────────────────────────────┐
│ 本页图片  23 张                            [×]   │
│ 尺寸：[小 23] [中 8] [大 3] [超大 0] [自定义]     │
│ 过滤：[URL 关键词________] 排序：[页面顺序 ▾]     │
│ 操作：[全选] [反选] [下载选中 0]                  │
├──────────────────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│ │ ✓  │ │    │ │ ✓  │ │    │ │    │ │    │        │
│ │1200│ │ 800│ │2000│ │ 640│ │1024│ │ 512│        │
│ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘        │
│  ……（首屏 24 张，滚动追加）                       │
└──────────────────────────────────────────────────┘
```

### 3.2 尺寸档位（本次核心）

按**短边**判定，避免竖图被误判为小图。

| 档位 | 短边阈值 | 说明 |
|---|---|---|
| 小 | ≥ 100 | 默认档，滤掉图标/装饰图 |
| 中 | ≥ 500 | 普通可用配图 |
| 大 | ≥ 1200 | 壁纸/高清素材 |
| 超大 | ≥ 2000 | 4K/印刷级 |
| 自定义 | 手填短边像素 | 特殊需求 |

- **每档实时显示命中数**（`小 23` / `中 8` / …），一眼看出该选哪档；
- 切换档位后网格只显示命中项，勾选集合**保留**（切回来还在）；
- 自定义输入 `≥ N`，非法值（空/非数字/负数）就地红字提示，不切换。

### 3.3 过滤与排序

| 能力 | 规则 |
|---|---|
| URL 关键词 | 子串匹配（大小写不敏感），与档位**同时**生效（交集） |
| 排序 | `页面顺序`（默认）/ `尺寸降序`（短边，相同按长边）/ `尺寸升序` |
| 空结果 | 显示「当前条件下没有图片」+ 一键重置 |

### 3.4 勾选

- 单击缩略图切换；选中态描边 + 右上角 ✓；
- `Shift+单击` 范围选择（以「上一次点击」为锚点，在**当前可见列表**内取区间）；
- `全选` = 选中当前过滤结果全部；`反选` = 当前过滤结果内取反；
- 勾选集合以 **URL** 为键（不是 DOM 下标，排序/过滤变化后仍然有效）。

### 3.5 批量下载

- 「下载选中 N」调 `VRImgBatch.download(items)`（I3 已实现的队列）；
- 进度显示在面板底部（复用 I3 的进度语义：`正在下载 x/N · 失败 y` + 取消）；
- 下载中面板保持打开，完成项缩略图打勾标灰；
- 关闭面板不中断下载（队列在 SW 侧跑）。

### 3.6 键盘

| 键 | 行为 |
|---|---|
| `Esc` | 关面板 |
| `J` / `↓` | 焦点下一张 |
| `K` / `↑` | 焦点上一张 |
| `X` / `Space` | 切换当前项勾选 |
| `Enter` | 下载选中（无选中则下载当前项） |
| `A` | 全选 |

输入框内不劫持（与 `VRKeys` 同口径）。

## 4. 模块边界

```
image-panel.js（VRImgPanel）
  ├─ 浮标：数量、拖动、关闭
  ├─ 面板：网格/档位/过滤/排序/勾选/键盘
  └─ 下载 → VRImgBatch.download(items)   ← I3 已有队列，不重写
```

- `image-panel.js` **不碰悬停逻辑**（归 `image-hover.js`），**不碰 SW**（归 `background.js`）；
- 面板与浮标都在**独立 Shadow DOM 宿主**里（`#vr-img-panel-host`），与悬停条宿主分开，
  避免一方 `teardown` 影响另一方；
- `VRImgBatch` 需要新增一个公开入口：

```js
VRImgBatch.download(items)   // items: [{url, candidates, title}]
// 返回 Promise<{ok, succeeded, fail}>
```

### 4.1 与 I3 的关系

I3 的 `startDownload()` 目前自己 `collectItems()`（扫描全页）。I4 需要「下载我勾的那几张」，
所以把「取 items」与「跑队列」拆开：

- `VRImgBatch.download(items)` —— 只跑队列（面板用）；
- 原「全部 N」按钮 —— 仍走 `collectItems()` + `download()`（行为不变）。

### 5.6 实施中踩的坑（都已修）

1. **浮标永远不出现**：`ensureUI()` 只在 `openPanel()` 里调，而浮标是入口，成了先有鸡还是先有蛋。
   修法：脚本末尾主动 `boot()`（`DOMContentLoaded` 兜底），并在设置从关→开时重建。
2. **Shadow DOM 焦点查不到**：`document.activeElement` 在 Shadow DOM 内只返回 host，
   `J/K/X` 全部失效。修法：读 `shadowRoot.activeElement`。
3. **`prompt`/`alert` 不可靠**：站点 CSP 可能拦原生弹窗。修法：自定义档位改**面板内联输入行**。
4. **自定义档位显示「0」**：未选阈值时 0 会被读成「一张都没有」。修法：初始显示「…」。
5. **`total` 与档位计数语义混淆**：`total` 是「扫描到的全部张数」（含 80px 这种不达任何档的），
   档位计数才是「达到该阈值的张数」。两者不能混着断言。
6. **短边判定必须用短边**：竖图 600×2000 若按宽或长边算会被误判成「大」，实际应算「中」。

### 5.7 测试脚手架的坑

1. **默认位置读 `style.right` 是空的**：默认值写在 CSS 里，要读 `getComputedStyle` 或算「距边距离」。
2. **中档张数算错**：`cover.jpg?v=m3` 短边 480 不到 500，不算中档。断言前先核对夹具真实尺寸。

## 6. 已知边界与风险

1. **只认 `<img>`**：CSS 背景图、`<picture>` 的 `<source>`、Canvas 都扫不到（与 I1/I2 一致，属已知范围）。
2. **懒加载图未解码**：`naturalWidth` 为 0 的图不进清单（`scanImages` 已过滤），滚动后才补进来。
3. **Shadow DOM 内的图**：不遍历所有 shadow root（只认事件路径），属已知边界。
4. **面板懒渲染**：首屏 24 张，滚动追加；极大页面（1000+ 图）首屏仍可能卡，I5 再优化。
5. **浮标关闭状态用 `sessionStorage`**：刷新恢复显示，符合原型口径。
6. **拖动位置用 `localStorage`**：跨站共享同一偏移，可能在某站不合适（I5 可按站点存）。
