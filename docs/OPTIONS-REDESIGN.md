# 设置页重设计（options.html）

> 日期：2026-10-24 ｜ 状态：已实施并验收（见 §11） ｜ 依据：现有页面 DOM/CSS 审计 + `ui-ux-pro-max` 设计引擎
> 目标：**不改功能、不改 ID、不改存储键**，只重做信息架构、视觉层级、控件排布与响应式。

---

## 1. 现状审计

### 1.1 结构盘点（改造前）

| 项 | 数量 | 说明 |
|---|---|---|
| 一级分区 `<section>` | **18** | 全部平铺，无分组 |
| 侧栏导航项 | **18** | 与分区一一对应，纯文字、无分组、无当前态 |
| 可交互控件 | **151 个唯一 ID** | 输入框 / 下拉 / 开关 / 按钮 |
| 按钮 | **47** | 主次不分，危险操作与普通按钮同款 |
| 内联 `style` | **40 处** | 宽度、边距、边框散落在 HTML 里 |
| 固定像素宽度 | 200 / 320 / 590 / 260 / 120px 等 | 不随容器收缩 |
| 重复 ID | `allDisable` / `allEnable` 各 **4 份** | HTML 非法，屏幕阅读器/标签关联会错乱 |
| 布局宽度 | `.wrapper` 固定 **45rem（720px）** | 大屏留白过多，小屏侧栏挤压内容 |
| 正文字号 | **13px**，标题 1.125em 且 `font-weight: normal` | 标题与正文几乎同级 |

### 1.2 具体问题（按严重度）

**P1 · 导航没有层级，18 项平铺**
侧栏从「资源库」直接跳到「抓取后缀」「正则」「Aria2」「关于」，用户无法判断哪些是抓取规则、哪些是外部工具、哪些是危险操作。18 项在 700px 高的窗口里已经需要滚动。

**P2 · 资源库分区是一锅粥**
9 个 `.item` 顺序堆叠：根目录 → 子目录 → 模式 → 自定义目录 → 索引状态 → 最近入库 → 索引维护 → 校验落盘 → 迁移。**配置、状态、维护、迁移**四种性质混在一起；迁移面板展开后整页再长 300px，且用内联 `border-top:#eee` 硬切。

**P3 · 行布局靠魔法数字**
`.item` 用 flex + `align-items:flex-end`，开关靠 `margin-right:50px`、下拉靠 `margin-right:85px`、Content-Type 靠 `margin-right:196px` 对齐。标签长度一变（中英文/i18n）就参差；窄窗口直接换行错位。

**P4 · 表格在窄窗口溢出**
`table{text-align:center}` + 固定列宽输入框（ext 100px / type 200px / regex 320px / URL 590px）。窗口 <760px 时横向溢出，删除图标仅 20px 点击区。

**P5 · 视觉层级过平**
每个分区一个 `h1.optionsTitle`（18 个 h1），字号 18px、常规字重；卡片阴影是 Material 的双层重阴影，白卡片落在白背景上只靠阴影区分；说明文字 `.explain` 同时承担「帮助」和「状态」，无法区分。

**P6 · 主次与危险操作不分**
47 个按钮里，只有 `.button2` 是蓝色，其余全白；但「保存」「校验」「写快照」「重置全部」「清空数据」「重启扩展」视觉权重几乎一样。重置按钮在每个分区重复 10 次，都是裸按钮。

**P7 · 保存无反馈**
输入 300ms 防抖直写 `chrome.storage.sync`，页面没有任何「已保存」提示；用户改完不知道是否生效。重置会整页 reload，也没有说明。

**P8 · 响应式基本缺失**
`css/mobile.css` 仅 16 行，只改了 `.wrapper` 右边距；侧栏仍是 `position:fixed; width:10rem`，靠 JS 算 `left`（`adjustSidebarPosition`）——窗口变窄时侧栏会被推到屏幕外或压住内容。

### 1.3 保留约束（重设计不能碰）

- 所有 `id`（151 个）与 `save="input|click|select"` 属性：`js/options.js` 靠它们回填/保存。
- `data-i18n` / `data-i18n-outer`：`js/i18n.js` 运行时填充。
- `.resetOption` 必须在 `.optionBox` 内：`options.js` 用 `closest('.optionBox')` 找本节可重置字段。
- `nav a[href^="#"]` 的平滑滚动绑定。
- `#extList` / `#typeList` / `#regexList` / `#blockUrlList` 四张表：行由 JS 动态生成（`<tr data-type=…>`）。
- 资源库相关 ID（`vrLib*`）与 `#vrLibMigPanel`：`settings.js` / `migrate-ui.js` 直接查询。

## 2. 设计目标

1. **找得到**：4 个组、18 个分区，组内不超过 8 项；侧栏有分组标签与当前分区高亮。
2. **看得懂**：分区标题 18px/600，卡片 12px 圆角 + 1px 边框；配置行「左标签 / 右控件 / 下行说明」三线对齐。
3. **改得对**：主操作（蓝）每屏最多一个；危险操作单独卡片、红色描边；保存有全局轻提示。
4. **挤不坏**：≥1024px 双栏（侧栏 236px + 内容自适应）；<980px 侧栏变顶部横向导航；表格横向滚动兜底，不截断功能。
5. **功能零变更**：不改存储键、不改事件、不改动态表格结构。

## 5. 组件规范

### 5.1 配置行

- 桌面：`display:flex; flex-wrap:wrap; gap:10px 16px`；首个标签块 `flex: 0 0 200px`；控件 `flex: 1 1 auto; min-width: 0`。
- 行间 `border-top: 1px solid var(--vr-border-soft)`，首行无边框，`padding: 12px 0`。
- 说明文字 `.explain` 12px，独占一行（`flex-basis:100%`）时用于状态/长提示。

### 5.2 开关

44×24 轨道、20px 滑块、`translateX(20px)`；关闭 `#cbd5e1`，开启 `--vr-primary`；`:focus-visible` 2px 外环；整行可点（label 包裹）。运行时为每个 `.switchInput` 从同行标签生成 `aria-label`（JS 注入，不改 HTML）。

### 5.3 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary `.button2` | 蓝底白字 | 保存 / 校验 / 写快照 / 预演 |
| Secondary `button` | 白底描边 | 刷新 / 选择目录 / 取消 |
| Danger `.btn-danger` | 白底红字红边 | 清空数据 / 重置全部 |
| Ghost `.resetOption` | 无边框、次要色 | 本节恢复默认 |

统一 34px 高、8px 圆角、13px 字号、`gap:8px`；禁用态 50% 透明度。

### 5.4 表格（4 张动态表）

- 外套 `.table-scroll`：`overflow:auto`、1px 边框、10px 圆角。
- `table` 左对齐、`min-width: 640px`；表头 12px/600、`--vr-surface-2`、sticky。
- 单元格 `padding:8px 12px`，输入框 100% 宽；删除图标 28px 热区、hover 红底。
- 窄屏保留横向滚动（规则表列多，强行堆叠会丢列语义），并在文档中注明。

### 5.5 状态与提示

- 状态行：12px，成功绿 / 警告橙 / 失败红；文本仍由原 JS 写入，不改逻辑。
- 全局「已保存」轻提示：监听 `chrome.storage.onChanged`，右下角 1.4s 淡出；不拦截任何操作。

拆成三张卡片，顺序即使用频率：

## 8. 交互与可访问性

- 侧栏当前分区高亮：`IntersectionObserver`（阈值 0.15）给对应 `nav a` 加 `.active`。
- 导航点击保留平滑滚动，`scroll-margin-top` 防标题贴边。
- 所有图标按钮补 `aria-label`（删除图标由 JS 注入）。
- 焦点可见：`:focus-visible` 2px 主色外环，`outline-offset:2px`。
- 删除/重置等破坏性操作保持原有 `confirm()`，不新增二次确认，避免改变流程。

### 11.3 与方案的偏差（有意）

1. **字体用系统栈，不引 Inter**：扩展离线运行，不能依赖 Google Fonts；系统栈在 Windows 上即为 Segoe UI/微软雅黑。
2. **宽表保留横向滚动**：4 张规则表列多且由 JS 动态生成，强行堆叠会丢列语义；滚动容器 + sticky 表头是更稳的取舍。
3. **重复 ID 顺手修掉**：`allDisable/allEnable` 改为 `data-all="0|1"`，JS 选择器同步，避免 8 个重复 ID 破坏标签/无障碍关联。
4. **移除侧栏 JS 定位**：旧 `adjustSidebarPosition()` 在窄窗口会把侧栏推出屏幕；改为 CSS sticky + 滚动高亮。
5. **保存提示走全局 `storage.onChanged`**：不动任何字段的保存/防抖逻辑，只在右下角给 1.4s 轻提示。

### 11.4 已知未覆盖

1. 未跑真实屏幕阅读器或 axe；只做了语义结构、`aria-label` 注入与键盘焦点。
2. 深色对比度按 token 设计（主按钮深色下改用 `#2563eb` 保证白字 ≥4.5），未逐项实测。
3. `<html lang="zh-CN">` 固定中文；原页面靠 i18n 运行时切换语言，此属性在切换后不会同步（原页面为 `en`，同样不准）。
