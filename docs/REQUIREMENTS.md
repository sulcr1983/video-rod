# 钓鱼竿 Video Rod — 需求规格说明书

> 版本：v1.0 ｜ 日期：2026-10-17 ｜ 状态：已确认（苏哥拍板）
> 配套文档：PLAN.md（方案书）、DESIGN.md（技术设计）、TESTING.md（测试）、DECISIONS.md（决策记录）

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 项目名 | 钓鱼竿 Video Rod |
| 类型 | Chrome 扩展（Manifest V3），个人自用 |
| 一句话定义 | 把网页里的视频/图片，按我想要的名字和文件夹，整整齐齐下到电脑上 |
| 底座 | fork 自猫抓 cat-catch v2.7.2（GPLv3），嗅探内核不动 |
| 分发方式 | 不上架、不公开、不分发；开发者模式 Load unpacked |

## 2. 用户画像与使用场景

**唯一用户**：苏哥（项目所有者），非技术背景，要求汇报用大白话。

**高频场景**：
1. 逛 B站：下纪录片分P、下大会员内容，一个链接搞定
2. 逛 YouTube：下播放列表、下教程视频
3. 逛小红书/推特：保存图片和视频，文件名要带原作者 ID，方便回找
4. 逛文章页/新闻页：保存内嵌视频，文件名用文章标题
5. 任意网页：看到想存的视频/图片，右键秒存，不想开面板

## 3. 范围

### 3.1 做什么（In Scope）

- 全站媒体嗅探（视频 + 图片 + 流媒体）
- 智能起名 + 自定义命名 + 批量命名
- 下载到自定义文件夹 + 按平台/作者自动分目录
- 批量下载 + 下载队列 + 面板内完成提示
- m3u8 自动合并 MP4；清晰度自动选最高
- 网页图片批量下载（扫描 + 过滤 + 同款卡片管理）
- 右键秒存（视频/图片）
- B站/YouTube 主动抓取（分P/合集/播放列表/频道/登录态内容）
- 快捷键唤起面板
- 去重检测（防手残重复下载）

### 3.2 不做什么（Out of Scope）

| 不做 | 原因 |
|---|---|
| DRM 加密站点（爱奇艺/腾讯/Netflix） | 全球无解，且苏哥明确不要，主攻 B站+YouTube |
| 上架商店 / 多用户 / 账号系统 | 纯自用 |
| 装 yt-dlp / Python / 任何外部程序 | 纯扩展内置 JS 实现（DECISIONS ADR-008） |
| 自动滚动页面抓懒加载内容 | 苏哥定：只抓已加载项（ADR-010） |
| 系统级通知 | 苏哥定：只要面板内 toast（ADR-013） |
| 直播录制 | P2 有余力再说 |

## 4. 功能需求

分级：**P0** 第一版必须 / **P1** 第二版 / **P2** 有余力再做。

### P0 — 第一批交付（11 项）

| # | 功能 | 用户故事 | 来源 |
|---|---|---|---|
| F1 | 全站视频嗅探 | 作为用户，打开任意视频页，面板自动列出所有可下载媒体 | 猫抓原生 |
| F2 | 清晰度自动最高 | 作为用户，多档清晰度时默认帮我勾最高档，不用手动选；设置里可关 | 猫抓原生 + 开关 |
| F3 | 智能起名 + 自定义命名 | 作为用户，文件名自动取文章标题/推文正文/带作者 ID，也能每条手动改、批量套规则 | 核心增量 |
| F4 | 下载到文件夹 | 作为用户，文件按 `平台/作者/` 自动进不同文件夹，每条也能指定目录 | 核心增量 |
| F5 | 批量下载 | 作为用户，勾选多条一键全下，名字目录互不干扰，完成后面板提示我 | 猫抓原生增强 |
| F6 | m3u8 自动合并 | 作为用户，一个流的几百个碎片自动拼成完整 MP4，不用我管 | 猫抓原生 |
| F7 | 网页图片批量 | 作为用户，小红书/微博这类图片页能批量扫图、滤小图、改名、统一下 | 新开发（抄四件套） |
| F8 | 右键秒存 | 作为用户，在视频/图片上右键直接下，不用开面板 | 抄 VDH |
| F9 | B站/YouTube 主动抓取 | 作为用户，B站分P/合集、YouTube 播放列表/频道、会员内容都能抓，失效自动退回嗅探 | 集成成熟实现 |
| F10 | 快捷键唤起 | 作为用户，按 Alt+Shift+V 随时唤起面板 | 抄 VDH |
| F11 | 完成提示 | 作为用户，下载完成后面板内 toast 告诉我结果 | 猫抓增强 |

### F3 智能起名详细需求

| 规则 | 需求 | 决策 |
|---|---|---|
| 文章页 | 取文章大标题，自动剥掉「标题_网站名」尾巴 | ADR-004 |
| 推特页 | 取推文正文：去「某人 在 X:」前缀、去引号、去 t.co 链接、换行压空格 | ADR-004 |
| 作者前缀 | 格式 `昵称(@账号)_标题.ext`；推特取 @handle+显示名，小红书取昵称+小红书号 | ADR-004 |
| 作者缺失 | 自动跳过该作者段，不留空下划线 | ADR-004 |
| 清洗 | 非法字符 `\ / : * ? " < > |` 换下划线；emoji 默认删除 | ADR-004 |
| 截断 | 超 60 字保留前 60 字 + 「…」 | ADR-016 |
| 重名 | 同页同名自动 `_01` `_02` | ADR-016 |
| 模板变量 | `${title}` `${post}` `${author}` `${site}` `${index}` `${date}` `${ext}` | ADR-004 |
| 批量命名 | 对勾选条目套用模板 | ADR-004 |

### F4 目录详细需求

| 规则 | 需求 |
|---|---|
| 默认总目录 | `Downloads/video-rod/`（下载目录下建总文件夹） |
| 自动分目录 | 小红书/推特等：`video-rod/平台/昵称(@账号)/`，与文件名作者双保险 |
| 手动指定 | 每条媒体可单独改子目录 |
| 快速选择 | 最近使用的文件夹 + 新建文件夹 |

### F7 图片扫描详细需求（抄业界四件套）

| 项 | 需求 |
|---|---|
| 扫描源 | `<img>` + srcset 最高分辨率 + `<picture>/<source>` + CSS 背景图 + 懒加载属性（data-src 等）+ shadow DOM + video 封面图 |
| 过滤 | 小于 100×100 跳过（滤图标/装饰图）；去重；data URI 处理 |
| 动态加载 | MutationObserver 监听懒加载/无限滚动 |
| 管理 | 与视频同款卡片（改名/目录/批量） |

### F9 主动抓取详细需求

| 站点 | 链路 | 约束 |
|---|---|---|
| B站 | BV号 → `x/web-interface/view`（分P）→ `nav` 拿 WBI keys → MD5 签名 → `playurl`（fnval=16/4048）→ DASH 音视频分离 → FFmpeg 合并 | Referer 必须 www.bilibili.com；keys 日轮换需缓存 |
| YouTube | content script 读 `ytInitialPlayerResponse`（全码率）/`ytInitialData`（播放列表）+ 签名 decipher + ffmpeg.wasm 合并音视频/字幕/封面 | 集成 Apache-2.0 代码需留版权声明 |
| 通用 | 只抓已加载项，不自动滚动；借浏览器 cookie 支持登录态；失效自动退回嗅探模式；两模块独立可开关 | ADR-009/010/011 |

## 5. 非功能需求

| 类 | 需求 |
|---|---|
| 隐私安全 | 纯本地运行，不上传任何数据；`.env` 等凭据严禁入 git；登录态只借本机 cookie，不外传 |
| 兼容性 | Chrome 当前稳定版 MV3；Firefox 兼容性不承诺（底座有 firefox manifest，但不作保证） |
| 性能 | 面板操作不卡浏览器；批量下载错峰排队；图片扫描不阻塞页面交互 |
| 可维护性 | **外壳大改、内核不动**：猫抓嗅探内核/下载器/合并链路一律不碰，保留 cherry-pick 上游能力；新功能全部独立模块，一个坏不影响其他 |
| 稳定性 | B站/YouTube 解析失效必须能自动退回嗅探模式，「永远有得下」 |
| 可回滚 | 每个里程碑一个 git 提交回滚点，改坏就地退 |

## 6. 验收标准（总则）

1. P0 全部功能可用，验收标准见 TESTING.md 用例表
2. 智能起名在 10 个真实网址（新闻/推特/B站/小红书/普通页）输出文件名个个干净
3. B站多P视频、YouTube 播放列表可一次性全下
4. 不装任何外部程序（yt-dlp/Python 等）
5. 每个里程碑结束苏哥验收通过才进下一阶段
