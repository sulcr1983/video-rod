## 1. 项目概述

| 项 | 内容 |
|---|---|
| 项目名 | 苏哥的钓鱼竿 |
| 类型 | Chrome 扩展（Manifest V3），个人自用 |
| 一句话定义 | 把网页里的视频/图片，按我想要的名字和文件夹，整整齐齐下到电脑上 |
| 底座 | fork 自猫抓 cat-catch v2.7.2（GPLv3），嗅探内核不动 |
| 分发方式 | **私有仓库、本机自用、不分发**；开发者模式 Load unpacked 安装；开源代码能抄就抄（ADR-028） |

## 2. 用户画像与使用场景

**唯一用户**：苏哥（项目所有者），非技术背景，要求汇报用大白话。

**高频场景**：
1. 逛 B站：下纪录片分P、下大会员内容，一个链接搞定
2. 逛 YouTube：下播放列表、下教程视频
3. 逛小红书/推特：保存图片和视频，文件名要带原作者 ID，方便回找
4. 逛文章页/新闻页：保存内嵌视频，文件名用文章标题
5. 任意网页：看到想存的视频/图片，右键秒存，不想开面板

## 3. 范围

### 3.1 做什么（In Scope）

- 全站媒体嗅探（视频 + 图片 + 流媒体）
- 智能起名 + 自定义命名 + 批量命名
- 下载到自定义文件夹 + 按平台/作者自动分目录
- 批量下载 + 下载队列 + 面板内完成提示
- m3u8 自动合并 MP4；清晰度自动选最高
- 网页图片批量下载（扫描 + 过滤 + 同款卡片管理）
- 右键秒存（视频/图片）
- B站/YouTube 抓取（B站分P/合集零签名对抗；YouTube 降级 P1，见 F9 改版说明）
- 快捷键唤起面板
- 去重检测（防手残重复下载）

### 3.2 不做什么（Out of Scope）

| 不做 | 原因 |
|---|---|
| DRM 加密站点（爱奇艺/腾讯/Netflix） | 全球无解，且苏哥明确不要，主攻 B站+YouTube |
| 上架商店 / 多用户 / 账号系统 | 纯自用 |
| 装 yt-dlp / Python / 任何外部程序 | 纯扩展内置 JS 实现（DECISIONS ADR-008） |
| 自动滚动页面抓懒加载内容 | 苏哥定：只抓已加载项（ADR-010） |
| 系统级通知 | 苏哥定：只要面板内 toast（ADR-013） |
| 直播录制 | P2 有余力再说 |

### F9 B站/YouTube 抓取详细需求（2026-10 改版：嗅探增强，零签名对抗）

> **改版背景（ADR-020）**：原「主动抓取」链路（B站 WBI 签名 / YouTube decipher）的前提已崩塌——
> bilibili-API-collect 2026-01-28 收律师函关停删码，B站下载开源生态 2026 年集体团灭；
> YouTube 2026-01 起强制 SABR+poToken，浏览器扩展是被打击最重的品类，
> 「2026 年没有 Chrome 扩展能可靠下载 YouTube 视频」。签名对抗路线作废。
>
> **新需求（核心思路：下载请求全部由浏览器自己发出，扩展零对抗）**：

| 站点 | 新链路 | 约束 |
|---|---|---|
| B站（P0） | 页面分P列表从 DOM/页面状态读取（**不调 API、不碰 WBI 签名**）→ 用户勾选 → 扩展驱动页面切换分P → 猫抓嗅探浏览器实际发出的 DASH 流（m4s 直链）→ 下载 + 合并 | Referer 必须 www.bilibili.com；大会员内容天然支持（浏览器能播放=请求已带 cookie） |
| YouTube（降级 P1） | 只走嗅探：浏览器播放时实际发出的流能抓多少抓多少；尝试从页面数据展开播放列表条目 | SABR 场景下可能只能抓到部分流；抓不到就标记「当前 YouTube 限制」，不投入签名对抗 |
| 通用 | 只抓已加载项，不自动滚动；借浏览器 cookie 支持登录态；失效自动退回纯嗅探模式；两模块独立可开关 | ADR-009/010/011 |

**YouTube 备选路（苏哥刚需时）**：猫抓内置 m3u8dl 协议外挂 N_m3u8DL-RE（本机装一个成熟程序，违背 ADR-008，但是 2026 年唯一稳路）。⏳ 待苏哥决定要不要走。

### 资源库需求（2026-10-24 拍板，方案见 LIBRARY-PLAN.md）

> 原始诉求：「下载网页平台的各种图片和视频，同时管理已下载的资料，用资源库的方式查看」。
> 方案与可交互原型：`docs/LIBRARY-PLAN.md` v1.3 + `deliverables/prototypes/library-prototype-v1.html` v1.3。

| # | 需求 | 落点 |
|---|---|---|
| R1 | 目录按 **平台 → 博主 → 图片/视频** 划分，用**中文**目录名 | `B站/小红书/X/YouTube/其他网页` + `视频/图片/音频` |
| R2 | 根目录单独文件夹，**默认下载到该目录，不每次启动授权**；设置里可自选文件夹，支持换根迁移 | 默认 `<Chrome下载目录>\video-rod`（零拷贝、不混日常下载）；`system`/`custom` 两种模式（LIBRARY-PLAN §4.5） |
| R3 | 文件名统一规范（日期 + 标题 + 清晰度 + 序号） | 复用 `naming.js`，不改内核 |
| R4 | 资源库页面按平台/博主/类型浏览，支持搜索、排序、时间线 | `library.html` |
| R5 | 图片可放大（缩放/拖拽/切换），视频点开即播 | 灯箱 + 自绘控件视频弹层 |
| R6 | **视频键盘：↑↓ 切换、←→ 调进度；自动播放、连续播放** | 自绘控件（原生 `controls` 会吞键） |
| R7 | **管理能力：删除权限**（软删除到回收站、可恢复、可重命名） | `_回收站` + 日志 + 二次确认 |
| R8 | 旧文件**可自动迁移**到新目录结构 | dry-run → 复制 → 校验 → 删源 → 回滚 |
| R9 | 借鉴开源产品的优秀交互，**但代码全部自研**（v1.3 追加） | 星标/标签/键盘导航/缩略图带/时间气泡 |

> `J/K/Enter/F` 键盘导航、灯箱底部缩略图带、视频进度条悬停时间气泡。

## 5. 非功能需求

| 类 | 需求 |
|---|---|
| 隐私安全 | 纯本地运行，不上传任何数据；`.env` 等凭据严禁入 git；登录态只借本机 cookie，不外传 |
| 兼容性 | Chrome 当前稳定版 MV3；Firefox 兼容性不承诺（底座有 firefox manifest，但不作保证） |
| 性能 | 面板操作不卡浏览器；批量下载错峰排队；图片扫描不阻塞页面交互 |
| 可维护性 | **外壳大改、内核不动**：猫抓嗅探内核/下载器/合并链路一律不碰，保留 cherry-pick 上游能力；新功能全部独立模块，一个坏不影响其他 |
| 稳定性 | B站/YouTube 解析失效必须能自动退回嗅探模式，「永远有得下」 |
| 可回滚 | 每个里程碑一个 git 提交回滚点，改坏就地退 |

## 6. 验收标准（总则）

1. P0 全部功能可用，验收标准见 TESTING.md 用例表
2. 智能起名在 10 个真实网址（新闻/推特/B站/小红书/普通页）输出文件名个个干净
3. B站多P视频、YouTube 播放列表可一次性全下
4. 不装任何外部程序（yt-dlp/Python 等）
5. 每个里程碑结束苏哥验收通过才进下一阶段
