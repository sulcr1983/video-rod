## 0. 一句话：这个项目现在到哪了

**"能下载"这一段已经成了，而且比市面上大多数工具都全；"存下来之后好不好用"这一段刚起步——界面设计完了，代码没改。**

## 4. 三个真实风险（不粉饰）

### 风险 1：合并后的代码没在浏览器里跑过

**这是当前最大的风险。** 41e1d80 那次合并，56 个 JS 文件语法全过、manifest 合法、引用文件不缺、零残留冲突标记——但**一次都没真正加载过**。

为什么没验：Chrome 156 禁止了命令行装扩展，我在下 Chrome for Testing（52 MB / 150 MB，网速 30–80 KB/s）。

**这条不通过，后面所有事都不该开工。**

### 风险 2：分辨率这件事，越拖越贵

代码里现在是这么个状况：

- 信息栏"分辨率"这一格，**写死成 `—`**（`lightbox.js:256`）
- 建索引的模块，**从来没往条目里写过宽高**
- 但是——生成缩略图的那一步，**其实看得到图片/视频的真实宽高**，只是看完就扔了

意思是：**那是唯一一次能看到真实分辨率的时机**。索引一旦建完，之后不再解码每个文件。现在补，加一行；拖到以后补，要把整个库重新解码一遍。

### 风险 3：我以为"标签丢了"，是我说错了

上一轮我跟你说"合并把标签功能弄丢了"。查证后**这句话不准确**：

- 数据字段 `tags: []` **一直在**
- 重建索引时也**专门保住了**标签
- 数据库索引也**建了**

**缺的只是界面入口**——信息栏里没有标签区、卡片上不显示。补个界面就行，不用重做。

**这条我更正一下，免得你按"重做"的预期来判断工作量。**

## 5. 你最担心的那件事：是不是白造轮子

**我认真查了，结论分两半，一半不好听，一半是好消息。**

### 不好听的一半：光做"素材库"，别人确实做得比我们好，而且早就完工了

| 现成方案 | 什么水平 | 和我们的关系 |
|---|---|---|
| **Eagle** | 商业软件，$29.95/年，最成熟，标签/来源/画布/智能分类全有 | 比我们的库**强一大截** |
| **TagStudio** | **GPL-3.0，7k star**，扫描现有目录不动文件，嵌套标签+别名，SQLite 存元数据，2026-08 还在更新 | 几乎就是我们想做的库，**但它是桌面软件（Python+Qt），Alpha 阶段** |
| **Monbooru** | AGPL-3.0，Go 单文件自托管，**SHA-256 去重 + 近重复检测 + 标签别名/蕴含 + 文件监视器 + 自动打标 + REST API** | 功能比我们的库**还全**，130 star，2026 年新项目、很活跃 |
| **Billfish** | 免费，Windows/macOS，有索引模式 | 成熟的免费替代 |
| **digiKam** | 开源摄影 DAM，RAW/EXIF/XMP 全套 | 摄影向，比我们专业得多 |
| **猫抓（我们上游）** | 嗅探 + 下载，**没有库** | 我们已经超过它 |

**所以：如果这个项目的目标只是"做一个本地素材库"，那确实是在重复造轮子，而且造不过人家。**

### 好消息：我们要做的那条链路，没人做完整

把这两件事拆开看：

```
    网页里的视频/图片  ──────────►  本地库（标签/搜索/预览/去重）
         ▲                                    ▲
         │                                    │
   猫抓、我们：会抓                       Eagle、TagStudio、Monbooru：会管
   但不会管                               但不会"从网页抓"
```

- **猫抓**：抓得很准，抓完就交给浏览器下载，**不管存到哪、不管从哪来**
- **Eagle / TagStudio / Monbooru**：管理很强，但**要你手动把文件拖进去**，或者只接受 URL
- **Monbooru** 有个浏览器插件（monsender），但它是"**把你当前页面地址发给我**"，不是"把这个页面里的视频流抓下来"

**没有产品把"在网页上看到 → 一键抓住 → 自动命名分文件夹 → 自动记下这条从哪个博主哪个帖子来的 → 在本地库里能搜到、能回到原帖"这条链走完。**

这就是我们的位置，也应该是我们后面所有投入的方向。

### 由此得出一条明确的资源纪律

| 该自己做的 | 该抄现成的 / 该做薄 |
|---|---|
| 网页媒体嗅探（各站适配） | 标签体系（照 TagStudio 的嵌套+别名） |
| 命名模板 + 自动分文件夹 | 查重（照 Monbooru 的 SHA-256 + 近重复） |
| **溯源记录**（作品页/博主/直链）—— 这是独一份 | 缩略图/预览/搜索（照 Eagle 的交互） |
| 下载任务与失败重试 | 画布/智能分类/自动打标（**不做**） |

一句话：**通用的库功能，往现成产品对齐，不自创；火力全部压在"抓下来就知道从哪来"。**
