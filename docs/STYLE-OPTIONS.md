# 界面风格四个方向（2026-11-04）

> 目的：先定**视觉语言**，再往这个方向细化原型。现在改的是"气质"，不是"功能"。
> 可交互原型：`deliverables/prototypes/style-explorations-v1.html`（顶部 5 个标签切换）

---

## 0. 一句话结论

**推荐「B 纸感」做界面 + 「D 影院」做预览层。**

界面浅色便于管理和看图片颜色，预览深色便于看视频。这不是折中，是这行的通行做法（Eagle、Lightroom、Photoshop 都是浅色界面 + 深色画布）。

---

## 1. 四款是什么关系

不是"四种配色"，是**四套视觉语言**。同一个按钮，在四套里的高度、圆角、边框、字重、配色都不一样：

| | A 图纸 | B 纸感 | C 画廊 | D 影院 |
|---|---|---|---|---|
| **像什么** | CAD / 影视后期 | 杂志 / 画册 | Pinterest | Netflix / Apple TV |
| 底色 | 深灰 `#15171B` | 暖白 `#F7F4EE` | 近白 `#FAFAFA` | 近黑 `#0A0B0E` |
| 圆角 | 3px（近直角） | 10px + 胶囊 | 16px（大圆角） | 8px |
| 分隔方式 | 1px 细线 | 底色差 + 柔阴影 | 阴影 + 留白 | 亮度差（无边框） |
| 标题 | 17px 无衬线 | **30px 衬线** | 24px 中黑 | 26px 粗体紧字距 |
| 数字 | 等宽字体 | 普通 | 普通 | 等宽 |
| 强调色 | 冷蓝 `#4C8DFF` | 赭石 `#A8502E` | 几乎没有（纯黑） | 暖橙 `#FF7A45` |
| 图标描边 | 1.5px | 1.75px 圆头 | 2px 圆头 | 1.5px |
| 一屏卡片 | 18 张 | 15 张 | 10 张 | 15 张 |

## 2. 每款的取舍

### A 图纸 —— 最专业、最耐看久盯，但冷

**优点**：信息密度最高，一屏 18 张；等宽数字让大小/时长能纵向对齐读；细线 + 直角没有多余装饰，看一天也不腻。

**缺点**：像工业软件，不像给个人用的东西；暗底看图片会**偏色**（暗背景上的图片显得更亮更饱和，你判断"这张图够不够亮"会失准）。

**适合**：如果你把这个工具当"下载流水线"用，每天处理几十条，看的是文件名和状态，不是画面。

### B 纸感 —— 最有品质感、最耐看，密度可调

**优点**：暖白底对图片颜色干扰最小；衬线大标题有"藏品册"的气质；留白舒服，不压迫。

**缺点**：衬线字体在 Windows 中文下会回退到宋体，**小字号会糊**。所以衬线只能用在 20px 以上的标题，正文必须无衬线——这是硬限制，不是偏好。

**适合**：如果这个库对你是"我收藏的东西"，会反复翻、会想给别人看。

### C 画廊 —— 图最突出，但最不适合"找文件"

**优点**：图片占绝对主导，界面几乎消失；4:5 竖版 + 文字压图，很像 Pinterest，刷起来爽。

**缺点**：一屏只看得到 10 张；标题压在图上，遇到浅色/花色封面时文字必然要打折（我把遮罩加到 0.82 才能保证可读，但已经把图压暗了）；找具体文件要一直滑。

**适合**：如果这个库主要是"看图"，不太需要按名字找。

### D 影院 —— 看视频最有氛围，看图片偏沉

**优点**：暗底 + 暖橙点缀，视频缩略图在暗背景上更亮眼；大标题紧字距很"片单"。

**缺点**：和 A 一样的问题——暗底看图片偏色；且长时间浏览图片，暗底比浅底更容易疲劳（对比度反差大）。

**适合**：如果库里以视频为主，且你经常全屏连播。

## 3. 控件层面的差异（这是"按钮菜单不满意"的关键）

同一个界面，按钮和菜单的差别比配色更能决定"像不像专业软件"：

| | A 图纸 | B 纸感 | C 画廊 | D 影院 |
|---|---|---|---|---|
| 主按钮 | 蓝色实心 30px / 3px 圆角 | 黑色胶囊 34px | 黑色胶囊 36px + 阴影 | 橙色渐变 34px + 发光 |
| 次按钮 | 描边 3px 圆角 | 描边胶囊 | 白底 + 微阴影 | 无边框深灰块 |
| 图标按钮 | 方形描边 | 圆形描边 | 圆形白底浮起 | 方形无边框 |
| 输入框 | 方形描边 30px | 胶囊 34px | 胶囊 38px 白底浮起 | 圆角 8px 深灰 |
| 开关 | 方形（像拨杆） | 胶囊 | 胶囊 | 胶囊 + 橙 |
| 标签 | 小方块描边 | 胶囊淡底 | 胶囊灰底 | 胶囊，选中橙底 |
| 右键菜单 | 3px 圆角、行高 24px、密集 | 10px 圆角、行高 28px | 14px 圆角、大阴影、行高 30px | 10px 圆角、深底、行高 26px |

**这一页在原型里是第 5 个标签「E 控件对照」**，四行并排看，差异比截图更直观。

我的判断：你现在觉得"按钮菜单不好看"，很可能不是颜色问题，而是**圆角和行高不成体系**——比如 7px 的卡片圆角配 999px 的胶囊按钮，两种语言混在一页里。

## 4. 我推荐 B + D 的理由

### 为什么是 B 做界面

1. **你的库里图片占一半**（36 条里 13 张静态图 + 5 个动图）。浅色中性底最不容易看错颜色。暗底会把图片"提亮提饱和"，你觉得图好看，导出去发现不是那个样。
2. **你要的是"管理"，不只是"看"**。B 的密度可以调——我把它从 4:3 压到 16:10 之后，一屏 15 条，不比 D 少。
3. **"钓鱼竿"这个名字有温度**。A 和 D 都像工业软件，B 更像"我的收藏"。

### 为什么预览层用 D

1. 看视频时周围暗下来是刚需，不然画面发灰。
2. 浅色界面 + 深色画布是 Eagle / Lightroom / Photoshop 的通行做法——不是折中，是各有各的活。
3. 技术上不难：预览层本来就是独立的一层（现在原型里已经是深色舞台），只是要把它做成**完整的深色 token**（约 30 个变量）。

### 代价

- B 需要**额外一套深色预览 token**，约半天。
- 衬线字体只能用于 ≥20px 的标题，正文必须无衬线（中文宋体小字会糊）。这条会限制一些排版想法。
- C 的"文字压图"在 B 里不能用（浅底 + 图 + 白字，遮罩要很重，会把图压暗）。

## 5. 需要你定三件事

| # | 问题 | 选项 |
|---|---|---|
| 1 | 整体走哪套 | A / B / C / D / **B+D（推荐）** |
| 2 | 如果选 B，标题要不要保留衬线 | 保留（有品质感，但只能大字号）／ 换回无衬线（更稳，但少一点味道） |
| 3 | 预览层要不要单独做暗色 | 要（推荐）／ 跟界面同色（省事，但看视频发灰） |

定完这三点，我按选定方向把主原型（主界面 + 设置页 + 收藏夹 + 预览）全部重做一版，再给你审批。

## 6. 一句提醒

这四款**功能完全一样**，都能做收藏夹、标签、溯源、连播、倍速。选的是"你每天打开它时的心情"，不是能力。

所以不用纠结"哪款功能更强"——挑一个你愿意天天看的。
