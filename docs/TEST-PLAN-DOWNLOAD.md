# 下载链路验收清单 · TEST-PLAN-DOWNLOAD v1.0

> 日期：2026-11-05 ｜ 依据：苏哥第一性原则（原话）：
> **单视频和图片可以在页面直接最简单的点下载，就自动下载到归档的文件夹里面去；还可以批量下图片和视频；然后可以自动改名，自动入不同的文件夹；再在资源库可以直接查看和管理。**
> 素材：`docs/TEST-ASSETS.md` A1-A9（9 条真实链接，浏览器已开好页签）
> 纪律：每条实测记录「操作→落盘路径→文件名→文件大小/可播放」；失败如实记证据，不静默跳过。

## 0. 验收总原则（四条，对应苏哥原话）

| # | 原则 | 判据 |
|---|---|---|
| P1 | **页面直接点下载** | 视频页有悬浮下载键 / 图片悬停有单张键，点一下即进下载队列，无需开 popup |
| P2 | **自动归档目录** | 落盘路径 = `<下载根>/video-rod/<平台>/<作者(@ID)>/<类型>/<文件名>`；类型目录 ∈ 视频/图片/音频 |
| P3 | **自动改名** | 文件名按命名规则生成（标题优先，非法字符清洗，长度截断，扩展名正确） |
| P4 | **批量图/视频** | 图片：悬停「全部 N」或清单面板批量；视频/混合：popup 批量勾选；都能一次多下 |
| P5 | **资源库查看管理** | 扩展库页能列出新下载条目、缩略图/信息正确、可预览、可重命名、可移入回收站 |

## 1. 逐条素材测试步骤

### A1 小红书 图文+视频（explore/6ad7233f…）
1. 打开页签，确认已登录（有头像）
2. 图片：鼠标悬停首图 → 出现「下载原图 / 全部 N」→ 点单张
3. 点「全部 N」批量下图
4. 视频（若笔记含视频）：悬停 → 点下载
5. 断言：P1 P2 P3 P4；落盘 `video-rod/小红书/<作者(@小红书号)>/图片|视频/`
6. 记录：张数、每张字节、是否原图尺寸（与页面显示对比）

### A2 小红书 图文笔记（discovery/item/6a065a7a…）—— 去后缀取大图
1. 悬停首图 → 单张下载
2. **四项对比**：页面原始地址 / 去后缀地址 / 落盘字节 / 实际分辨率
3. 断言：落盘图 ≥ 页面显示图（去后缀生效）；若相等或更小，如实记「未取到更大图」

### A3 YouTube Shorts（_XS4l8VivP4）
1. 视频页 → 悬浮下载键（默认最高画质，N-05）
2. 断言：P1 P2 P3；落盘 `video-rod/YouTube/<频道(@handle)>/视频/`；mp4 可播放、时长≈原片
3. 记录：分辨率（ffprobe 或文件信息）、体积、是否有音轨

### A4 X @NASA（x.com/NASA）—— 批量
1. 主页 → popup 或页面批量入口
2. **批量下 10 条图/视频混合**
3. 断言：P4；逐条落盘 `video-rod/X/NASA(@NASA)/图片|视频/`；10 条全部成功或如实记失败条目

### A5 花瓣 pin（huaban.com/pins/6293511672）—— 通用通道
1. 若出现人机验证，先过验证或如实记「被验证拦截」
2. 单张下载 → 批量下载
3. 断言：P1 P2 P4；**不要求专站适配**（ADR-051），失败则定位是通用通道哪一环（懒加载/render 图未嗅到）

### A6 抖音（v.douyin.com/8pGobUZIy84 → douyin.com/video/…）
1. 视频页 → 悬浮下载键
2. 断言：P1 P2 P3；落盘 `video-rod/抖音/<作者(@抖音号)>/视频/`；mp4 可播放（注意 Referer 403 已由后台处理）

### A7 微博 @地球知识局（weibo.com/u/5750600479）—— 批量
1. 主页 → 批量下 10 条图片+视频
2. 断言：P4 P2；`video-rod/微博/<博主(@uid)>/图片|视频/`；微博 CDN 需页面上下文，确认无 403/.htm 残件

### A8 B站（BV17Rxm6wEud）—— 登录态高画质
1. 视频页 → 悬浮下载键 / popup
2. 断言：P1 P2 P3；落盘 `video-rod/B站/<UP(@mid)>/视频/`；分辨率符合默认最高（1080P+，按账号权限）
3. 记录：清晰度、体积、音视频是否合并

### A9 Instagram reel（无登录）
1. 打开 reel → 观察是否有登录墙
2. 若可播：悬停/悬浮键下载；断言 P1 P2 P3
3. 若被墙：记录拦截证据（截图/提示文案），B-03 继续挂「待账号」，不算失败

### A10 TikTok reel（leon.111219）—— 通用性（含不自动播放页）
1. 打开页签，**先别点播放**；把鼠标悬停到视频上 → 通用通道应自动静音播放并嗅到 mp4 直链
2. 出现悬浮下载键 → 点它
3. 断言：P1 P2 P3；落盘 `video-rod/TikTok/leon.111219/视频/`；mp4 可播放
4. 若仍下不了：记录「悬停后是否已播放（video.paused / readyState）」与「后台嗅探条数」，据此定位是嗅探通道还是命名/落盘

## 2. 资源库管理与查看（P5，全部下完后统一验）

在扩展库页 `chrome-extension://<id>/library.html`：
1. 列表包含本次新下载条目，数量与磁盘一致
2. 平台/作者/类型/大小/时间字段正确（不是"未分类"）
3. 树编号：新平台出现对应编号，博主挂在平台下
4. 预览：图片可放大/旋转；视频可播放/倍速/进度；信息面板无重复字段
5. 管理：重命名落盘生效；移入回收站可恢复
6. 搜索：`关键词`、`词1 词2`（交集）、`-词`（排除）命中正确
