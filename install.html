它能干什么 What it does

三件事，装好就顺手 Three things, ready to go

01

下载即归档 Filed as it lands

按 来源网站 → 博主 → 内容 自动分层，落进指定文件夹，进去就是整整齐齐，同一博主自动归在一处。 Filed by site → creator → collection the moment it lands — no cleanup afterwards.
02

自动命名，还能溯源 Named & traceable

用 标题、博主昵称、序号、日期 拼文件名，重名自动 _01；每条都记住原帖地址，随时找得回。 Auto-named from title, creator, index, date; every item keeps its source page.
03

一个装完就够 One is enough

通用嗅探覆盖任意网页，微博、抖音、小红书、Instagram、X、YouTube、B站还有深度适配，不用为某个站单独装插件。 Universal sniffing for any page, plus deep support for the sites you use most.
装完先做这一件事 Do this first

媒体库，在另一个页面里 The library lives on its own page

上面说的搜、筛、溯源、倍速播放，全在媒体库里。它不是那个小弹窗——弹窗一关就没了；媒体库是独立网页，关掉也一直在，所以值得放进收藏夹。 Searching, filtering, tracing back, playback speed — all in the library. It is not that little popup (that one disappears when closed); the library is a real page that stays. Worth a bookmark.

chrome-extension://__EXT_ID__/library.html

加了收藏夹之后，浏览器收藏栏会多一个「媒体库」，以后点一下就进来，不用每次去翻扩展图标。也可以手动复制上面的地址，在收藏夹里「添加网页」粘贴进去。 Once bookmarked, a "Library" entry appears in your bookmarks bar — one click from anywhere. You can also copy the address above and paste it into a manual bookmark.
