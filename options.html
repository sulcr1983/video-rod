图片下载

鼠标停在图片上会出现下载按钮；右下角浮标可以打开整页清单。改动即时生效，与清单面板里的设置是同一份数据。

悬停按钮
停在图片上时出现「下载原图」
全部按钮
悬停条上显示「全部 N」
右下浮标
本页图片清单入口
优先原图
按五级候选找最大的一张；关掉则用当前显示的那张
扫描 CSS 背景图
很多站点把封面做成背景图，只看 img 会漏掉；长页面上会略慢
悬停门槛（显示尺寸）
页面上的图宽高都 ≥ 此值才出「下载原图」按钮，范围 16–4096。判的是显示尺寸，不是原图像素
面板最小尺寸（原图像素）
图片清单只列原图短边 ≥ 此值的图，范围 16–4096；与上面的悬停门槛互不影响
悬停延迟（毫秒）
停多久才出按钮，范围 0–1500
批量并发
同时下载几张，范围 1–8；太高反而排队更慢
单批上限
一次最多下多少张，范围 1–2000
拖拽下载
把页面上的图拖到右下角接收区即保存；只在拖动时出现，平时不占页面
框选下载
按住 Alt 在页面上拖出矩形，框内的图一次性下载
快捷键
Alt+Shift+D 下载悬停图 / Alt+Shift+A 打开清单（可在 chrome://extensions/shortcuts 改键）

规则命中即**不显示**在图片清单里。域名留空或写 * 表示全网； 正则可写 ad_ 或 /\.gif$/i，留空表示该域名下所有图片。 示例：域名 sinaimg.cn + 正则 /avatar → 屏蔽微博头像。

本 fork 做了什么

  • 本地资源库主线（S0–S2）：三段中文目录、下载完成自动入库、迁移三形态（预演 / 复制 / 校验 / 回滚）、索引三源（下载记录 / 快照 / 全量扫描）与缺失校对。
  • 桌面端下载链路：文件名保护（绕开 Chromium 579563）、X 推文内联下载、右键秒存与快捷键、面板浅色化。
  • 设置页重设计：18 个平铺分区收敛为 4 组导航，重做卡片层级、响应式与深色模式。
  • 资源库浏览页：概览 KPI / 平台分布 / 博主速览，全宽大图网格 + 真表格、筛选搜索与懒生成缩略图。
  • 查看器：图片缩放/拖拽、信息面板、缩略图带；视频自绘控件与键盘操作（↑↓ 切条、←→ ±5s、Shift ±30s、空格、连播）。
  • 删除与回收站：右键 / ⋯ 菜单、软删除到 _回收站、单条/整批恢复、彻底删除、清空与操作日志。
  • 图片悬停下载：调研、方案 v1.2 与可交互原型（实现待排期）。
  • 工程化：文档先行、每步验收；8 套 CDP 自动化回归，覆盖 246 条断言。
