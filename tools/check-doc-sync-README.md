# 文档-代码一致性核查工具

## 用途

检查 `docs/*.md` 里引用的文件路径、函数名、消息协议是否在代码里真实存在。
**目的：防止文档漂移**（文档写着某个文件，实际不存在 / 实际换了名字）。

## 用法

```bash
python tools/check-doc-sync.py          # 只报告
python tools/check-doc-sync.py --fix    # 报告 + 输出建议修正
```

## 设计原则

1. **区分「规划」与「现状」**：设计文档写「（新）」的是计划，不算漂移；
   HANDOFF / 实现记录写的是现状，必须与代码一致。
2. **能力比文件名重要**：`js/sw-library.js` 改到 `js/library/sw-library.js` 是**搬家**，
   不算能力缺失——报告里要指出「实际在哪」。
3. **白名单**：已知的、有意保留的差异写进 `PLANNED` 集合，不报警。

## 输出

- ❌ 失效引用（文档说存在、代码里没有，且不属于规划）
- ⚠️ 位置变更（文件搬家了，文档还写旧路径）
- ℹ️ 规划项（设计文档里的「新增」，未实现是正常的）
