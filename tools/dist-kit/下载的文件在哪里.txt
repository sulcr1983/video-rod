下载的文件在哪里？
====================

一句话：默认在【下载】文件夹里的 `video-rod` 目录，按「站点 / 作者 / 类型」分好类了。


一、默认位置
------------

  Windows ：C:\Users\<你的用户名>\Downloads\video-rod\
  Mac     ：/Users/<你的用户名>/Downloads/video-rod/

进去以后大概是这个结构：

  video-rod\
    youtube.com\
      频道名\
        视频\
          视频标题.mp4
    bilibili.com\
      作者名\
        视频\
          视频标题_画质.mp4
    xiaohongshu.com\
      作者名\
        图文\
          笔记标题_01.jpg
          笔记标题_02.jpg

为什么这样分：同一个作者的素材会堆在一起，找的时候不用满硬盘翻。

文件名规则可以在设置里改（支持 ${title} ${author} ${index} ${date} 这些占位符）。


二、怎么改保存位置
------------------

  1. 点浏览器工具栏上的扩展图标，打开主面板
  2. 面板右上角进「设置」
  3. 找到「默认文件夹」（或者叫「保存目录」）
  4. 改成你想要的名字/路径，比如 D:\素材\钓鱼竿

注意：只改「默认文件夹」这个名字，改的是子目录名；
      要换整个盘符，用下面第三条的「授权目录」。


三、想存到别的盘 / 移动硬盘
---------------------------

浏览器出于安全限制，扩展默认只能往【下载】文件夹里写。
想存到 D 盘、E 盘、移动硬盘，需要在设置里授权一次那个文件夹：

  1. 主面板 → 设置 → 找到「授权保存目录」（有的版本叫「选择文件夹」）
  2. 选你想要的文件夹，浏览器会弹一个确认框
  3. 点「允许编辑」

授权一次就一直有效。之后所有下载都会存到你选的目录里，
而且是扩展直接写盘（不经过浏览器的下载列表），速度更快、不会丢目录结构。


四、想改浏览器的默认下载目录
----------------------------

  1. 浏览器右上角三个点 → 设置
  2. 搜索「下载」或直接找「下载内容」
  3. 改「位置」

改完以后，扩展的 video-rod 目录会跟着建在新位置下面。


五、文件下完了但列表里没看到？
------------------------------

先看是不是存到了别的地方：

  · 在扩展主面板的「素材库」里搜一下标题
  · 素材库里点任意一条，详情里有「文件路径」，直接告诉你文件在哪
  · 还找不到就在扩展管理页点「重新加载」，再按 F5 刷新页面

如果素材库里有记录但硬盘上没文件，多半是被手动删了/移走了 ——
素材库里那条会显示「文件缺失」，右键可以清理掉。


六、清理时注意
--------------

  · 只删文件不会影响扩展，但素材库里的记录会变成「文件缺失」
  · 想彻底清空：素材库 → 回收站 → 清空回收站（会同时删文件）
  · ⚠️ 别删 video-rod 这个文件夹本身，那是下载根目录，删了下次会自动重建，
       但已下的文件就找不回来了
