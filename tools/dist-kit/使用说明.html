安装说明 · Video Rod

把这个扩展装进浏览器

这个文件夹是自带的：扩展本体就在里面，不需要从任何商店下载。 跟着下面四步做，两分钟就能用。

版本 __KIT_VERSION__ · Edge / Chrome 通用

先说清楚：这文件夹是什么

你现在拿到的这个文件夹，可以直接拷到任何一台 Windows 或 Mac 上使用。 里面的 extension 子文件夹就是扩展程序本体， 浏览器可以直接加载它。

使用说明.html 就是你现在看的这一页，随时可以再打开
extension\ 要导入的就是这个文件夹（里面是 manifest.json 和所有代码，约 4.4 MB）

01打开扩展管理页

在浏览器的地址栏里，把下面这一行粘进去，按回车：

edge://extensions

用 Chrome 的话，地址是 chrome://extensions —— 点右边的按钮可以换：

chrome://extensions
💡 也可以点浏览器右上角的 三个点 → 扩展 → 管理扩展，一样能到。 注意：这些地址不能直接点链接打开，复制后要手动粘到地址栏再按回车。

02打开「开发者模式」

在扩展管理页的左下角（Chrome 在右上角），有一个 开发者模式的开关，把它打开。

🔓 打开后会多出几个按钮，其中 「加载解压缩的扩展」 也在左上角（Chrome 在左上角）—— 我们下一步就要用它。

03点「加载解压缩的扩展」，选 extension 文件夹

  • 点左上角出现的「加载解压缩的扩展」

    会弹出一个选择文件夹的窗口。

  • 找到本文件夹里的 extension 子文件夹

    重要：要选到 extension 这一层，不是选它的上一层， 也不是选里面更深的 js、css。 判断标准很简单：这个文件夹里能直接看到 manifest.json 就是对的。

  • 选中后点「选择文件夹」

    扩展会立刻出现在列表里，名字叫 苏哥的钓鱼竿。

⚠️ 如果提示 「清单文件缺失或不可读取」，说明选错了层 —— 多半是选了 extension 的上一层。退回去重新选，进到能看到 manifest.json 的那一层。

04确认装好了

列表里出现「苏哥的钓鱼竿」就成功了。接着做三件事确认能用：

  • 把扩展图标固定到工具栏

    点浏览器右上角的拼图图标 🧩 → 找到「苏哥的钓鱼竿」→ 点旁边的小图钉。 这样以后一键就能打开。

  • 打开任意一个视频页面

    鼠标移到视频上，右上角会出现一个下载小按钮；点它就能下最高清。 有些站要先让视频播几秒，扩展才嗅探得到地址。

  • 点工具栏图标打开主面板

    能看到当前页面的视频/图片列表，还有「素材库」入口 —— 下载过的东西都在那儿，按平台和作者分好类。

以后换电脑 / 重装系统怎么办

把整个文件夹拷过去，重复上面四步就行。扩展本体在文件夹里， 不怕找不到来源。

📌 文件夹不要删、不要改名、不要移动。 浏览器是「就地从这个文件夹加载」的，不是复制一份存起来 —— 文件夹一挪，扩展就会失效，需要在扩展页重新加载一次。

如果换电脑后想保留以前下载的记录和素材库，把原来电脑上 下载目录里的 video-rod 文件夹一起拷过去，放到同样的位置即可。

几个常见问题

  • 每次打开浏览器都提示「请停用开发者模式扩展」

    这是浏览器的正常提示，点「关闭」或右上角的 × 就行，不用点「停用」。 自己加载的扩展都会这样，不影响使用。

  • 下完的文件去哪儿了？

    默认在 下载文件夹 里的 video-rod 目录， 再按「站点 / 作者 / 类型」分级。具体路径和改法看文件夹里的 「下载的文件在哪里.txt」。

  • 为什么有些网站下不了？

    加密播放、只给分片的直播这类，地址是临时的。点视频上的下载按钮 → 展开菜单 → 最后一项「录下来」，它会一边播一边录（录多久就要播多久）。

  • 提示「扩展已更新，请刷新本页面」

    在扩展页点一下「重新加载」，然后按 F5 刷新那个网页即可。
